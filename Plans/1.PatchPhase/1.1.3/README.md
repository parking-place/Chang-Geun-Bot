# 1.1.3 — 조회 페이지와 재생 상태 화면

- 상태: **PLANNED — 문서만 작성, 구현·LXC 시험·개발 인수 미실행**
- 포함 항목: **F-02, F-03, F-05**. [전체 항목 배정](../ITEM_COVERAGE.md)을 따른다.
- 목표: 긴 조회 결과를 Discord 안에서 탐색하고, 승인 만료 곡을 정확히 골라 새로 요청하며, 현재 재생 상태를 확인한다.
- 실행·상태·증거 기준: [공통 규칙](../EXECUTION_RULES.md), [STATUS](../STATUS.md), [시험 추적](../TEST_MATRIX.md).

## 기존 동작과 추가할 차이

| 항목 | 현재 구현 | 이번 버전의 변경 |
| --- | --- | --- |
| F-02 | 긴 일반 조회는1900자를 넘으면 전체 `list.txt` 첨부; 제안함 조회25건; 주시 목록 페이지 있음 | 일반 목록·대기열·검색·제안함을 페이지와 총건수로 탐색; 제안함25건 이후도 조회 |
| F-03 | 승인 만료 항목을 큐에 보존하고 새 DJ의 명시 재생으로 재승인 가능 | 기존 만료 항목을 단건 선택하는 요청 화면; 새 승인 규칙을 만들지 않음 |
| F-05 | `/현재곡` 제목과 일시정지·계속·넘기기·정지 버튼 | 준비/재생/일시정지 상태, 볼륨, 반복 모드, 다음 유효 곡, 안전한 원본 참조 |

기존 JSON 내보내기와 긴 결과 파일 전달은 유지한다. 페이지 도입을 긴 결과 수신 기능의 최초 구현으로 표시하지 않는다.

## 선행과 경계

- [1.1.0](../1.1.0/README.md)의 동적 prefix 권한 회귀와 오류/계측 계약을 선행한다.
- [1.1.2](../1.1.2/README.md)의 조회·선택 계약과 안정적인 대상 ID 처리를 재사용한다.
- 실제 음성에서 주시 변경의 영향을 확인하는 전체 인수는 [1.1.5](../1.1.5/README.md)의 R-03에 연결한다.
- 시간 이동·일괄 재승인·주기적 메시지 갱신·새 자연어 문법은 범위에 넣지 않는다.

## 사용자 명령과 화면 계약

아래 화면/버튼 확장은 **구현 예정**이다. 기존 명령 이름을 유지하고 같은 목적의 명령을 중복 등록하지 않는다.

| 진입점 | 예정 동작 | 권한 |
| --- | --- | --- |
| `/목록 보기`, `/대기열 보기`, `/검색` | 이전/다음·총건수·현재 페이지 표시 | 기존 일반 조회의 서버/텍스트 채널 정책 |
| `/제안함` | 대기 제안 전체를 페이지로 탐색 | 기존 DJ 전용 제안함 정책 |
| `/대기열 보기`의 `만료 곡 선택` | 선택한 기존 항목의 `재생 요청` 버튼 제공 | 선택 조회와 실제 DJ 재생 권한을 분리 |
| `/현재곡` | 상태 정보와 기존 제어 버튼, 명시 `새로고침` | 조회와 재생 제어 각각의 기존 정책 |

페이지는 최대10항목을 기준으로 실제 문자열 길이에 따라 더 줄인다. 표시 제목을 줄여도 선택 값은 원본 ID를 유지한다.
페이지/재생 버튼은 요청자·서버·채널에 결합하고 조작 때 최신 권한을 확인한다. 다른 사용자는 본인 명령으로 새 화면을 연다.
슬래시로 연 화면에는 정적 명령 채널 정책을 적용한다. prefix 응답에 붙는 화면은 입증된 원래 출처와 현재 주시 세대를 계승한다.
조회 화면이 다른 경로의 권한 예외를 획득하거나 일반 음악 명령 허용 채널을 넓히지 않는다.
재생 요청은 현재곡이 있으면 기존 큐 동작을 따르고, 대기 상태일 때만 기존 시작 규칙을 따른다. 선택만으로 즉시 소리를 내지 않는다.

## 데이터·취소·응답 계약

- 표시 번호는 조회 snapshot에 결합한다. 수정은 entry ID와 기대 버전으로 전달하며 번호만 다시 해석하지 않는다.
- 목록/큐 변경 후 오래된 페이지나 선택은 갱신을 요구한다. 탐색 전체에서 같은 snapshot의 누락/중복0을 검증한다.
- 재승인은 최신 DJ·동일 음성·채널/주시 세대·음원 지원 여부를 검증하고 기존 entry를 재사용한다.
- 중복 버튼·오래된 선택·주시 끄기/제거·권한 회수는 중복 승인/큐 복제/늦은 시작을 만들지 않는다.
- 다음곡은 현재 유효한 승인 후보를 표시한다. `준비 중`을 실제 재생으로, 승인 만료를 미디어 실패로 표시하지 않는다.
- 화면 조회/페이지/구조화 재생 버튼은 Jev0회다. 원문 대화·키·signed media URL은 화면/계측에 넣지 않는다.
- 경과시간은 이번 범위에서 생략한다. 새 저장이 필요하면 additive migration으로 검토하고 기존 승인/중복 기록을 보존한다.

## 완료·중단·rollback

해당5단계와 P113-01~07을 고정 후보에 연결해 검증하고 사용자 조작 결과를 기록한다. 자동 회귀를 실제 청취 결과로 표시하지 않는다.
잘못된 항목 선택, 무단 승인, 현재곡 손실, 취소 후 시작이 있으면 후보 적용을 중단하고 실패 증거를 보존한다.
UI 이상은 검증된 이전 화면/후보로 복귀한다. DB 변경이 있으면 이전 바이너리와 호환되는 이전 DB 묶음을 함께 사용한다.
새 DB·감사·승인·tombstone을 삭제하거나 중계 예산을 초기화하지 않는다. 복귀 후 새 명시 요청 전 자동 재생하지 않는다.
이 버전의 개발 인수만으로 이전 미완료 W·독립 품질·실제100회·8시간·정식 출시를 완료 처리하지 않는다.
