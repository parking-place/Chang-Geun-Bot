# 전체 제안의 버전 배정표

사용자가 요청한 **기능 F-01~09, Jev 최적화 J-01~09, 안정화 R-01~08의26개 전부**를1.1.0~1.1.7에 배정했다. 각 ID의 전체 책임 버전은 하나이며, 공통 보호·선행 준비·후속 회귀는 여러 버전에서 수행할 수 있다. 모든 버전의 개발 작업이 시작됐지만 전체 인수는 미완료다. R-04 첫 독립 품질 FAIL, R-06 백업 검증 사용자 지정 SKIPPED 등 실제 결과는 [현황](STATUS.md)과 [시험표](TEST_MATRIX.md)를 따른다. 배정 자체는 구현/시험 완료를 뜻하지 않는다.

최적화의 배정은 무조건 설정을 바꾸라는 뜻이 아니다. 비교 결과가 나쁘면 기준 유지 결론을 근거와 함께 남기는 [공통 판정](EXECUTION_RULES.md)을 적용한다. 이 규칙은 해당 항목을 미실행으로 빼는 예외가 아니다.

## 제안 원본과 범위

[기능 원본](01_FEATURE_IDEAS.md), [Jev 최적화 원본](02_JEV_OPTIMIZATION.md), [안정화 원본](03_STABILITY_AND_ACCEPTANCE.md)의26개 ID가 기준이다. 예시로만 언급하고 당시 별도 검토로 둔 시간 이동·복합 자연어 실행·개인 추천·다중 서버/음성방·DJ 역할 설정 확장은 이26개에 포함되지 않는다. 로컬 모델 재도입·다른 사용자 간 의미 캐시·숨은 재시도 등 추천하지 않은 접근도 채택하지 않는다.

새 하위 아이디어가 생기면 기존 ID에 조용히 섞지 않고 추가 ID/버전/권한/검증 범위를 기록한다. 이번 배정에서 빠진 정식 제안 ID는 없다.
