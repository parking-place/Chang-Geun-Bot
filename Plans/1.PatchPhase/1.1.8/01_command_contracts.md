# 01 — 전체 명령과 인자 계약

- 상태: **IN_PROGRESS — C01~C47 등록부와 주요 실행 경로 작성, 공개 옵션/상호작용 전수 검증 전**
- 책임: F-10, J-10. 시험: P118-01.
- 입력: [47개 명령·8개 상호작용 대응표](COMMAND_COVERAGE.md), [기존 도메인 계약](../../../bot/src/changgeun/domain/models.py).

## 작업

1. 실제 슬래시 등록 트리에서 명령·옵션·선택값·기본값을 추출하는 **LXC 검사**를 설계한다. C01~C47과 I01~I08 각각에 최소 정상/누락 인자/권한 거절/오류 사례를 연결한다. 자연어 구문 하나만 등록하고 전체 지원으로 세지 않는다.
2. 명령 등록부에 안정적인 명령 ID, 한국어 설명/예시, 서비스 동작, 필수·선택 인자 schema, 선택값/범위/기본값, 권한, 입력 출처, 결과 공개 범위, 확인 조건, 상태 조회 범위, 시험 ID를 둔다. 도움말·슬래시·NLP가 이 계약을 공유하도록 설계한다. 기존 명령을 선언형으로 옮길 때 명령 이름/기본값/권한의 불필요한 변경을 금지한다.
3. `ActionPlan`으로 끝나는 작업과 도움말·현재곡 화면·YouTube 검색·주시·운영 조회처럼 별도 서비스가 필요한 작업을 명시적으로 분류한다. 자연어 해석기는 **등록된 typed command intent**만 만들고 실제 plan/서비스 호출은 신뢰하는 봇 코드가 구성한다. 임의 함수명·SQL·새 URL·Discord ID를 모델 결과에서 실행하지 않는다.
4. 슬래시 handler의 권한 확인·메타데이터 조회·snapshot·확인·실행·응답 생성을 공통 애플리케이션 서비스로 추출한다. prefix를 가짜 Discord interaction으로 꾸며 handler를 통째로 재호출하는 방식 대신 본문/첨부/답장 참조가 있는 입력 문맥과 공개/비공개 응답 인터페이스를 정의한다. 이미 동작하는 파일 출력은 보존한다.
5. `/재생`과 `/계속`의 내부 여러 단계는 하나의 등록된 사용자 작업으로 유지한다. 임의 복합 명령을 실행하는 workflow 엔진은 추가하지 않는다. 주시 설정은 `WatchService`와 관리자 grant를 재사용하며 `SETTINGS_UPDATE`나 직접 SQL로 우회하지 않는다.
6. `PLAYLIST_RESTORE`·`SETTINGS_UPDATE`는 공개 범위 밖의 내부 동작으로 목록에 명시한다. `QUEUE_ENQUEUE`는 기존 재생 흐름의 내부 수단으로 연결한다. 새로운 공개 명령이 추가되거나 기존 옵션이 달라지면 대응표/회귀에 누락이 있는 후보를 거절한다.

## 인자 원본과 출력

실제 인자값은 사용자 입력의 검증된 구간, 등록 자료, Discord가 제공한 첨부/채널 참조 또는 명시된 기본값에서만 만든다. 모든 최종 인자에 `input span / selected entity / default / current state` 출처를 내부적으로 남긴다. 이름·검색어·태그 등 자유 텍스트는 길이/형식 검사를 통과해야 하고, 임의 모델 생성 문자열을 원문 값으로 간주하지 않는다.

입력에 없는 필수값은 질문한다. 불명확한 중복/교체/부분읽기 허용은 안전한 기본값을 유지하거나 별도로 질문한다. 조회 결과는 명령에 맞는 페이지·제어·첨부 형식을 유지한다. 관리자 데이터와 확인 미리보기의 비공개 여부를 출력 단계까지 전달한다.

## 산출물과 종료 조건

- 구현 시 예상 영역: 새 명령 등록부/입력·출력 계약 모듈, `discord_adapter/client.py`, `mention.py`, `watch.py`, `application/executor.py`, `domain/models.py`. 새 파일명은 구현 시 확정하며 이번 계획에서 비어 있는 제품 파일은 만들지 않는다.
- C01~C47·I01~I08의 모든 동작과 공개 옵션에 handler/인자/권한/확인/응답/시험이 연결돼야 한다. 등록된 명령 집합과 대응표의 차집합0이 필수다.
- 동일 fixture에서 슬래시와 자연어가 같은 최종 동작·인자·권한·확인·상태 변화를 만드는 대조 시험을 LXC에서 수행한다. 비결정적 시드/시간은 fixture로 잠그고 모델이 만들지 않게 한다.
- 문서/등록부 검사만으로 제품 전체 지원 PASS를 표시하지 않는다.
