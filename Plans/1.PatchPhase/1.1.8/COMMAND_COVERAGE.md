## 옵션과 표현의 추가 검증

- C07은 기존 규칙 범위인 곡수1~100, 최근 제외0~365일, 최대 길이1~86400초, 포함/제외 태그 각각 최대20개와 기본값을 등록부에 옮긴다. 명시하지 않은 조건은 기존 기본값을 미리보기에 표시한다. 곡 부족 시 임의 조건 완화로 채우지 않는다.
- C08은 입력 파일512KiB 상한과 링크/파일 양자택일을 유지한다. JSON은 봇이 읽는 자료이고 파일 전체·첨부 다운로드 URL을 Jev에 보내지 않는다. 교체/부분읽기/중복 허용을 한 “예”로 동시에 켜지 않는다.
- C10에서 언급하지 않은 필드는 보존한다. “태그 추가”는 현재 목록을 읽어 기존 교체 실행기의 최종 값을 계산하는 방식으로 설계하고, 전체 교체·비우기는 명시한다. 슬래시 기본값의 기존 의미를 무심코 바꾸지 않는다.
- 제목/목록명에 `삭제`, `정지`, `그리고`가 포함돼도 인용된 데이터로 취급한다. 부정된 대상과 실제 대상, 저장 목록과 대기열, “다음 곡”과 “다음 페이지”를 구분한다.
- C23은 `https://` 없는 `youtube.com/watch?...`·`youtu.be/...`, 영상/목록 URL 구별을 회귀한다. 모호한 검색어를 현재 목록으로 치환하지 않는다. C37의 기본 대상은 **서버 최신 편집**이지 자동으로 요청자의 마지막 편집이 아니다.
- 모든 위치는 사용자에게1부터 표시하고 안정적인 entry ID·snapshot 버전에 결합한다. 동일 제목·같은 곡의 중복 항목·페이지 번호를 각각 시험한다.
