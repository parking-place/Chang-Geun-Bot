## 제안 근거 문서

[기능 아이디어](01_FEATURE_IDEAS.md), [Jev 최적화](02_JEV_OPTIMIZATION.md), [안정화 과제](03_STABILITY_AND_ACCEPTANCE.md)는 제안의 원인·현재 구현과 차이를 보존한다. 우선순위 P0/P1/P2는 조사 순서이며 배정 제외나 완료 표시가 아니다. 현재 책임 버전은 위 로드맵과 배정표를 따른다.

## 진행 원칙

1. 권한/계측 기반부터 통신·후보/조회·사용 편의·미디어·관리로 진행한다.
2. 독립 평가 데이터, 변경 전 백업, 인증서 잔여 유효기간 확인은 초기부터 준비한다. 최종 책임 버전이 뒤에 있다는 이유로 보호 작업을 미루지 않는다.
3. 정식 출시에는 해당 고정 후보의 필수 증거와 앞선 미완료 조건이 필요하다. 과거328/41회귀나 개발37문장, 후속1.1.7 성적을 다른 SHA의 전체 PASS로 복사하지 않는다.
4. 문서 작성으로 제품 VERSION·태그·API 예산·채널/서비스 설정을 변경하지 않는다.
