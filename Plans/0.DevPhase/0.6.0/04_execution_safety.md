## 목표

`jev-api`에서 한국어가 어떻게 해석되어도 슬래시·버튼과 같은 권한·확인·트랜잭션·중복·상태 검사를 통과해야 실행되도록 한다. [추론 프로필](../INFERENCE_PROFILES.md)에 따라 Jev API 점수와 무관한 부정문·감상·프롬프트 주입·상태 경쟁을 안전 회귀로 고정한다.

## 로컬 코드 작업

- 봇이 ActionPlan의 actor/guild/action/target/expected versions/source request ID·실제 단계/공급자 호출 수·provider/profile_id/config_hash를 구성한다.
- actor는 인증된 Discord 이벤트, 대상은 DB/snapshot, 확인 여부는 봇 정책에서 가져온다. 모델 권한·승인 주장을 무시한다.
- 명시적 `playlist.*`, `queue.*`, `playback.*`, `voice.*`, `catalog.*`, `proposal.*`, `settings.*` allowlist와 인자 스키마를 적용한다.
- 미해결 필드가 남은 중간 후보는 실행하지 않는다. 활성화되지 않은 P1 동작은 미지원 안내로 끝낸다.
- 실행 직전에 실제 DJ 역할·같은 음성채널·채널 접근·세션 generation·대상 ID/버전·요청 만료를 재검증한다.
- 권한 조회 실패·추론 중 DJ 해임·target 삭제/변경은 거절한다. 모델 재판단으로 권한 실패를 덮어쓰지 않는다.
- 자연어 곡/항목 삭제는 항상 미리보기와 확인, 목록 전체 삭제/덮어쓰기/queue 교체·비우기·대량 변경도 확인한다.
- 확인 토큰을 요청자·guild·target ID·예상 버전·작업 내용·실행 세대에 묶고 TTL 60초로 제한한다. 승인 시 재검증하고 시험 설정·후보 변경 전의 토큰/세션을 새 실행에서 사용하지 않는다.
- 버튼 후보 선택은 규칙으로 계획을 완성하고 모델 0회를 유지한다. 다른 사람이 확인하거나 만료 토큰을 재사용하지 못하게 한다.
- `빼지 마`, `틀지 말고 저장`, `지우지 말고 뒤로 보내`, 감상 `별로네`를 동작 제한/안전 회귀로 다룬다.
- 제목의 명령/주입 문자열은 데이터로 처리하고 독립 복합 명령은 분리 안내한다.
- 중복 명령의 DB 변경 1회, DB commit 뒤 성공 응답, 취소·퇴장·만료 뒤 늦은 결과 폐기를 보장한다.
- hosted 전송 취소가 외부 계산 중단을 보장하지 않아도 봇 실행은 차단한다. 전송불명 요청의 예산을 환불하거나 다른 프로필로 재판단하지 않는다.

## 산출물

- 공통 실행기 연결·ActionPlan 승격·확인 토큰·재검증·안전 안내 코드와 회귀시험.
- 부정문/주입/복합 명령/경쟁 fixture, 모델 결과와 실제 실행 계획의 대조 감사 필드.
- 자연어 실패 시 슬래시/버튼 대체 안내 및 기존 재생 유지 정책.

## LXC 검증

- [B-04·B-07·B-08·B-09·B-10](../TEST_MATRIX.md)의 잘못된 응답/후발 결과 미실행·이전 확인 토큰 차단·설정 비교 이중 변경 방지·장애 중 구조화 기능 유지를 공통 실행기에서 회귀 검증한다.
- DiscordBotLXC에서 설치·빌드·lint·타입 검사·mock 실행/확인/트랜잭션 시험을 수행한다. Jev API 실제 프로필 통합 시험은 같은 fixture/seed/snapshot에서 독립 DB·큐·원장·run으로 순차 실행하며 실제 Discord 변경을 shadow 방식으로 두 번 재생하지 않는다.
- N-04/05/06/07 부정문·감상, N-11 권한 주장, N-12 주입, N-13 독립 복합 명령을 시험한다.
- N-18 중복 변경, N-19 DJ 해임, N-20 queue 순서 변경, N-30 최종 단계 뒤 상태 변경을 주입한다.
- N-31 높은 점수 삭제 확인, N-34 UI 선택 뒤 모델 0회, T-03/04/05 비DJ 경로를 확인한다.
- 확인 타인의 클릭·TTL 초과·역할 해제·target version 변경과 DB 쓰기 실패를 검사한다.
- 설정·후보 변경 전 확인 토큰·늦은 응답·문맥의 재사용을 차단하고 게이트웨이 profile/hash 불일치에도 구조화 기능이 유지되는지 확인한다.

## 통과 기준

- 비DJ 변경 전건 차단, 부정문/모호 삭제의 무확인 실행 0건, 상태 경쟁의 잘못된 항목 수정 0건.
- timeout·취소·퇴장 뒤 실행 0건, DB 성공 전 성공 응답 0건, 중복 변경 0건.
- Jev API 실제 프로필에서 슬래시·버튼·자연어의 공통 실행/권한/확인 동작이 일치하고 프로필 간 데이터/토큰 재사용이 0건이다. mock 통과로 실제 경로의 안전 증거를 대체하지 않는다.

## 중단·후속 처리

안전 실패는 평균 정확도가 높아도 버전 차단 사유다. 해당 자동 해석 경로를 UI로 제한하고 원인을 수정한 뒤 같은 경쟁 조건을 LXC에서 다시 검증한다. 안전 정책을 점수 임계값 조정으로 대체하지 않는다.

## Jev API 전용 인수 범위

2026-09-27 사용자 결정에 따라 실제 제공자는 `jev-api` 하나다. [전용 계약](../INFERENCE_PROFILES.md)을 따른다. 과거 로컬 모델 시험은 보존 기록이며 이 단계의 선행 조건이나 출시 게이트가 아니다. 권한·확인·데이터·최대3단계/3 dispatch·전체12초/단계4초·실패 후 추가 전송0 규칙은 유지한다. hosted 내부 forward와 미공개 model revision은 null/unavailable로 남긴다.
