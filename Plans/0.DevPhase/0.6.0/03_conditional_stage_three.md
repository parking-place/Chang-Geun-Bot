## 목표

[Jev API 실제 프로필](../INFERENCE_PROFILES.md)에서 실제 근거로 좁힐 수 있는 단일 행동의 잔여 대상·범위에만 마지막 후보 선택을 사용한다. 세 번째 판단은 사용자 확인·권한 승인·새 정보 생성 기능이 아니다.

## 로컬 코드 작업

- API stage 3/task `resolve_context`를 1→2 유효 완료 뒤에만 호출한다. 중간 단계 생략·병렬 후속 호출을 만들지 않는다.
- 세부 행동 확정, 잔여 필드가 단일 행동의 대상/참조/범위, 실제 데이터·유효 동일 사용자 문맥의 소수 후보를 진입 조건으로 둔다.
- 후보 간 판별 근거가 없으면 선택 메뉴로 바로 전환한다. 같은 별칭 두 곡뿐인 상황은 추측하지 않는다.
- 권한·세션·snapshot 버전·요청 상태·단계/공급자 호출 예산·잔여 시간을 진입 직전에 검사한다.
- `third_stage_enabled=true`, 상한 3, 정책 `unresolved_context_only`, 잔여 시간 최소 기본 1,000ms일 때만 허용한다.
- 원문·최소 문맥·검증된 행동·후보·근거 출처만 전달한다. 이전 모델의 자유 설명/높은 점수를 사실 근거로 넣지 않는다.
- 앞 단계 행동을 고정한다. `playlist.item.add`가 확정된 경우 재생 시작/queue 교체 같은 부수 행동을 후보로 넣지 않는다.
- 현재곡은 최초 snapshot ID를 사용하고 단계 사이의 새 현재곡으로 자동 치환하지 않는다.
- selected ID·행동 일관성·candidate set·확률·usage·고정 provider/profile_id/config_hash를 검사하고 충돌/후보 밖/프로필 변경이면 미실행으로 끝낸다.
- `clarify`·계산 만료·결과 불명확 뒤 네 번째 호출, 다시 1단계 루프, 새 숨은 ID 자동 재시도·다른 공급자 fallback을 금지한다. hosted timeout/전송불명 상태도 예약을 환불하거나 재호출하지 않는다.
- UI 후보 선택은 규칙으로 계획을 완성하며 모델 추가 호출 없이 권한/대상/버전을 재검증한다.
- 최종 후보에도 자연어 삭제·대량 변경·덮어쓰기 확인 정책을 그대로 적용한다.

## 산출물

- 3단계 진입 predicate·최종 후보·행동 고정·충돌 검증·UI 전환 코드와 시험 코드.
- 유효 선행 문맥 예시와 근거 없는 동일 별칭 사례의 대조 fixture.

## LXC 검증

- [B-05·B-06·B-07·B-08](../TEST_MATRIX.md)의 3단계 호출 상한·중복/재시도 차단·공통 기한·요청 중 프로필 변경 거절을 최종 판단 경로에서 회귀 검증한다.
- DiscordBotLXC에서 설치·빌드·lint·타입 검사·진입 조건 mock 시험을 수행한다.
- DiscordBotLXC의 봇·중계에서 `jev-api`를 순차 선택해 같은 fixture/seed/snapshot으로 N-23 근거 있는 최근 목록 참조와 N-25 근거 없는 후보를 대조한다. run/DB/원장은 독립 분리한다.
- N-14 불명확 종료, N-28 잔여 시간 부족, N-29 계산 기한 초과, N-32 행동 충돌/후보 밖을 확인한다.
- hosted 내부 forward는 실측했다고 보고하지 않는다.
- N-30 현재곡·DJ·버전 변경, N-31 높은 삭제 점수에도 확인 유지, N-34 UI 선택 뒤 추가 모델 0회를 검사한다.
- N-24의 앞 단계 clarify와 N-10 동일 별칭에 3단계가 호출되지 않는지 실제 계측한다.

## 통과 기준

- 근거 없는 3단계·clarify 뒤 재추론·4단계/루프·권한/확인 우회가 모두 0건이다.
- Jev API 프로필에서 최대 공급자 호출 3회·행동 고정·snapshot 대상 유지·UI 뒤 추가 호출 0회를 만족한다.
- 3단계의 해석 개선과 추가 지연을 별도로 보고하고 단순 요청 조기 종료를 유지한다.

## 중단·후속 처리

세 번째 질문이 추측·점수 개선·승인용으로 사용되면 차단하고 UI로 전환한다. 상한과 확인 정책을 암묵적으로 완화하지 않는다.

## Jev API 전용 인수 범위

2026-09-27 사용자 결정에 따라 실제 제공자는 `jev-api` 하나다. [전용 계약](../INFERENCE_PROFILES.md)을 따른다. 과거 로컬 모델 시험은 보존 기록이며 이 단계의 선행 조건이나 출시 게이트가 아니다. 권한·확인·데이터·최대3단계/3 dispatch·전체12초/단계4초·실패 후 추가 전송0 규칙은 유지한다. hosted 내부 forward와 미공개 model revision은 null/unavailable로 남긴다.
