## 추론 프로필 적용

[Jev API 전용 계약](../INFERENCE_PROFILES.md)을 따른다. 실제 자연어 판단은 `jev-api`만 사용하며 봇과 TLS 중계·영속 원장은 DiscordBotLXC에서 별도 계정으로 실행한다. 현재 배치는 [환경 계약](../ENVIRONMENT.md)을 따른다. `mock`은 지정 LXC의 격리 회귀 전용이다. 구조화 명령은 추론 없이 실행하고, API 장애가 기존 재생·슬래시·버튼을 막지 않게 한다.

## 범위

- generation·세션 버전·desired/actual state·guild별 실행 직렬화.
- 저장 목록과 독립된 대기열·재생/다음추가/지금재생·현재곡 제어.
- 반복·셔플·볼륨·대기열 편집/저장·확인 후 채널 이동·실제 패널.
- 유휴 타이머·최소 재시도/연속 실패·강제 퇴장·늦은 콜백·재시작 보존.
- T-07~20 실제 인수와 기존 T-01~03·05·06·10 구조화 회귀.

## 범위 밖과 후속

- 자연어 T-04 및 N 시나리오 전체는 0.6.0이다. Jev API 선택 및 Jev 장애와 분리된 기본 동작은 유지한다. 구조화 요청의 모델 호출수는 0이다.
- 태그 생성·제안함·가져오기·내보내기·되돌리기는 0.7.0에서 완성한다.
- 기본 취소/재시작/타이머 안전은 이 버전에 구현하며 8시간·부하·OOM·디스크·백업/복원은 0.8.0에서 강화한다.
- 사용자 승인에 따라 YouTube 직접 오디오는 1.0.0 범위에서 제외하고 비활성으로 유지한다.

## 버전 종료 게이트

실제 허용 source와 DAVE 환경에서 핵심 T 시험·구조화 회귀가 통과하고 취소 뒤 실행·current 중복·잘못된 항목 수정이 없어야 한다. mock만 성공한 실재생 기능은 완료로 표시하지 않는다. T-04/자연어·편의·운영 gate가 남으므로 전체 제품 완성과 구분한다. 현재 상태는 계획 / 미구현 / 미검증이다.


## Jev API 전용 인수 범위

2026-09-27 사용자 결정에 따라 실제 제공자는 `jev-api` 하나다. [전용 계약](../INFERENCE_PROFILES.md)을 따른다. 과거 로컬 모델 시험은 보존 기록이며 이 단계의 선행 조건이나 출시 게이트가 아니다. 권한·확인·데이터·최대3단계/3 dispatch·전체12초/단계4초·실패 후 추가 전송0 규칙은 유지한다. hosted 내부 forward와 미공개 model revision은 null/unavailable로 남긴다.
