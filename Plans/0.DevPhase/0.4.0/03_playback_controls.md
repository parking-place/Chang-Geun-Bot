## 목표

- 현재곡 제어가 명세의 정지/계속/스킵/반복 의미를 정확히 따른다.
- 재생 중 대상 교체와 채널 이동을 확인 후 처리한다.

## 추론 프로필 적용

[Jev API 전용 계약](../INFERENCE_PROFILES.md)을 따른다. 실제 자연어 판단은 `jev-api`만 사용하며 봇과 TLS 중계·영속 원장은 DiscordBotLXC에서 별도 계정으로 실행한다. 현재 배치는 [환경 계약](../ENVIRONMENT.md)을 따른다. `mock`은 지정 LXC의 격리 회귀 전용이다. 구조화 명령은 추론 없이 실행하고, API 장애가 기존 재생·슬래시·버튼을 막지 않게 한다.

## 로컬 코드 작업

로컬은 코드·문서 작성과 읽기 검토만 한다. 모든 설치·검사·시험·build·오디오 실행은 LXC에서 수행한다.

- /지금재생은 current 중단을 알리고 확인 후 선택곡을 시작하며 기존 current는 queue 앞에 보존한다.
- /일시정지·/계속은 위치 보존 재개와 정지/퇴장 후 처음부터 재개를 구분한다. /정지는 연결 유지, /퇴장은 보존 후 연결 해제한다.
- /넘기기는 한곡 반복에서도 동일 entry를 즉시 다시 틀지 않는다. queue 순환에서도 해당 회차에 스킵 항목을 즉시 재삽입하지 않는다.
- /셔플은 대기항목만 섞고 current/저장 목록을 유지한다. 반복 끄기/한곡/대기열 모드와 /볼륨 0~100 검증을 작성한다.
- 재생중 채널 이동은 중단/보존/취소 범위를 미리보기하고 requester·버전·권한 확인 후 이전 세션 취소→선택 채널 이동으로 처리한다.

## 산출물

- 재생 제어 핸들러·반복/셔플/볼륨 정책.
- 정지/퇴장 current 보존과 수동 스킵 기록/반복 회차 관리.
- 지금재생·재생중 이동의 확인 미리보기/실행 코드.

## LXC 검증

- DiscordBotLXC에서 T-13·14·16과 FakeAudioSource 상태/순서 시험 후 실제 테스트 음성 검증을 수행한다.
- 정지→계속, 퇴장→재개 요청, 반복중 스킵, 중복 stop/leave, 지금재생 취소/확인을 검사한다.
- 동일/다른 음성채널 DJ·권한 해제·이동 확인 중 current/queue 변경·볼륨 범위 밖 값을 검사한다.

## 통과 기준

- T-13·14·16 실제 시험에서 확인 누락·current 중복·즉시 잘못된 반복 0건이다.
- 정지/퇴장 후 재개는 항목 처음부터 시작하며 일시정지 재개만 위치를 유지한다.
- 스킵된 항목의 영구 기록은 재생 이력이며 저장 목록 자동 변경/삭제가 없다.

## 중단·후속 처리

- 제어 실패·확인 범위 불일치·보존 중복이면 해당 동작을 닫고 상태기계 공통 전이를 수정한다.
- 오디오 재생을 되감는 undo 기능은 제공하지 않는다. 목록/queue 편집 undo는 0.7.0에서 버전 조건으로 제한한다.

## Jev API 전용 인수 범위

2026-09-27 사용자 결정에 따라 실제 제공자는 `jev-api` 하나다. [전용 계약](../INFERENCE_PROFILES.md)을 따른다. 과거 로컬 모델 시험은 보존 기록이며 이 단계의 선행 조건이나 출시 게이트가 아니다. 권한·확인·데이터·최대3단계/3 dispatch·전체12초/단계4초·실패 후 추가 전송0 규칙은 유지한다. hosted 내부 forward와 미공개 model revision은 null/unavailable로 남긴다.
