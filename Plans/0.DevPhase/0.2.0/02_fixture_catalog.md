## 목표

- 외부 제공자 없이도 내부 등록 카탈로그를 정확히 검색·선택하고 목록 편집을 검증한다.
- 원제목·게시 채널·운영자 정보와 항목 대상 범위를 구분한다.

## 추론 프로필 적용

[Jev API 전용 계약](../INFERENCE_PROFILES.md)을 따른다. 실제 자연어 판단은 `jev-api`만 사용하며 봇과 TLS 중계·영속 원장은 DiscordBotLXC에서 별도 계정으로 실행한다. 현재 배치는 [환경 계약](../ENVIRONMENT.md)을 따른다. `mock`은 지정 LXC의 격리 회귀 전용이다. 구조화 명령은 추론 없이 실행하고, API 장애가 기존 재생·슬래시·버튼을 막지 않게 한다.

## 로컬 코드 작업

로컬은 작성·읽기 검토만 한다. 모든 설치·정적 검사·시험·build·Discord 실행은 LXC에서 한다.

- 테스트 guild 전용 fixture 카탈로그와 명시적 seed 입력을 작성한다. 운영 카탈로그를 가짜 곡으로 자동 채우지 않는다.
- 내부 검색 우선순위를 ID/영상 ID→정확 제목/별칭→정규화 이름→부분 일치로 구현한다.
- 유사 제목·라이브/리믹스·같은 별칭·짧은 이름은 후보 ID 기반 메뉴로 선택한다. 첫 검색 결과를 자동 정답으로 확정하지 않는다.
- 곡 정보에 원제목·게시 채널·길이·운영자 표기/메모를 분리해 표시하고 원본 필드를 별칭으로 덮어쓰지 않는다.
- 외부 URL/목록 등록·검색은 0.3.0 제공자 의존으로 미구현 표시한다. 저장 성공이나 재생 가능이라는 가짜 응답을 만들지 않는다.

## 산출물

- 내부 검색·검색 결과 pagination·후보 선택 어댑터.
- 동명/다른 업로드/중복 ID/다른 guild fixture와 source 상태 표시.
- 현재 버전의 fixture 입력 범위와 0.3.0 외부 제공자 연결 계약.

## LXC 검증

- DiscordBotLXC에서 내부 검색 단위/mock 시험과 테스트 Discord 선택 메뉴를 확인한다.
- 검색 결과의 안정적인 ID·guild 경계·메뉴 만료·다른 사용자 클릭·삭제된 대상 클릭을 시험한다.
- 외부 URL 입력과 미지원 소스를 실제로 넣어 미구현/미지원 안내만 나오고 목록/대기열이 바뀌지 않는지 검사한다.

## 통과 기준

- 사용자 선택 전에 비슷한 다른 곡·버전이 등록되지 않는다.
- 원본 제목과 운영자 표기가 분리되고 검색 조회에 필요한 시스템 캐시와 DJ 편집 권한이 혼동되지 않는다.
- T-02·06의 fixture 곡 준비가 가능하지만 외부 메타데이터·재생 PASS로 기록하지 않는다.

## 중단·후속 처리

- 모호한 검색의 임의 선택·타 guild 노출·외부 입력 가짜 성공은 버전 진행을 중단한다.
- 별칭/태그 운영 UI와 다양한 실제 카탈로그 검증은 0.7.0, 외부 메타데이터는 0.3.0으로 넘긴다.

## Jev API 전용 인수 범위

2026-09-27 사용자 결정에 따라 실제 제공자는 `jev-api` 하나다. [전용 계약](../INFERENCE_PROFILES.md)을 따른다. 과거 로컬 모델 시험은 보존 기록이며 이 단계의 선행 조건이나 출시 게이트가 아니다. 권한·확인·데이터·최대3단계/3 dispatch·전체12초/단계4초·실패 후 추가 전송0 규칙은 유지한다. hosted 내부 forward와 미공개 model revision은 null/unavailable로 남긴다.
