## 목표

- 구조화된 Discord 입력을 공통 실행기와 연결하고 긴 작업도 제때 접수 응답한다.
- 서버 관리자 설정과 DJ 편집/재생 권한을 분리한다.

## 추론 프로필 적용

[Jev API 전용 계약](../INFERENCE_PROFILES.md)을 따른다. 실제 자연어 판단은 `jev-api`만 사용하며 봇과 TLS 중계·영속 원장은 DiscordBotLXC에서 별도 계정으로 실행한다. 현재 배치는 [환경 계약](../ENVIRONMENT.md)을 따른다. `mock`은 지정 LXC의 격리 회귀 전용이다. 구조화 명령은 추론 없이 실행하고, API 장애가 기존 재생·슬래시·버튼을 막지 않게 한다.

## 로컬 코드 작업

로컬은 작성·읽기 검토만 한다. 모든 설치·정적 검사·시험·build·Discord 실행은 LXC에서 한다.

- Discord 어댑터를 구성하고 테스트/운영 토큰 분리·허용 guild/채널·현재 실행 범위의 필수 비밀값 누락 시 시작 중단을 작성한다.
- 슬래시 명령 그룹과 옵션 스키마를 선언한다. /재생 곡·목록 동시 지정은 거절하고 아직 미구현인 음성/자연어 기능을 비활성으로 표시한다.
- 실제 이벤트의 actor/guild와 Discord 역할·채널 접근정보를 정책 입력으로 변환한다. 메시지의 권한 주장을 사용하지 않는다.
- 슬래시/버튼 검색 요청은 작업 전에 defer/접수 응답하고 결과·기한/취소 처리 경로를 분리한다.
- /설정 보기와 관리자 DJ역할·호출채널·음성정책 설정, 서버 소유자 초기 설정, settings_version·변경 이력을 연결한다.

## 산출물

- Discord 초기화·명령 등록·상호작용 접수 어댑터 소스.
- 설정 조회/변경 핸들러와 한국어 도움말 초안.
- 필수 Discord 권한·Intent·테스트 앱 설정 목록. 비밀값은 문서/로그에 넣지 않는다.

## LXC 검증

- DiscordBotLXC에서 설치·lint·타입검사·mock 시험 후 실제 테스트 Discord 앱에 명령을 등록한다.
- 3초 내 초기 응답을 확인하고 인위적으로 느린 저장/조회 경로가 첫 응답을 기다리게 하지 않는지 검사한다.
- 일반 멤버·DJ·관리자 비DJ·서버 소유자 조합과 권한 조회 실패·허용되지 않은 채널을 검사한다.

## 통과 기준

- T-03의 실제 슬래시 비DJ 변경 차단에서 DB/대기열 변경 0건이다.
- 설정 변경은 관리자에게만 허용하고 관리자 비DJ 편집은 기본 거절한다.
- Jev 미연결 상태에서도 구조화 목록/설정 기능이 동작하고 실제 토큰은 증거에 노출되지 않는다.

## 중단·후속 처리

- 접수 기한·권한·토큰 분리 실패 시 실제 기능 확대 전에 수정한다.
- 자연어 /부탁·멘션·일반 호출어 실행은 0.6.0이다. 현재는 미구현 안내만 허용한다.

## Jev API 전용 인수 범위

2026-09-27 사용자 결정에 따라 실제 제공자는 `jev-api` 하나다. [전용 계약](../INFERENCE_PROFILES.md)을 따른다. 과거 로컬 모델 시험은 보존 기록이며 이 단계의 선행 조건이나 출시 게이트가 아니다. 권한·확인·데이터·최대3단계/3 dispatch·전체12초/단계4초·실패 후 추가 전송0 규칙은 유지한다. hosted 내부 forward와 미공개 model revision은 null/unavailable로 남긴다.
