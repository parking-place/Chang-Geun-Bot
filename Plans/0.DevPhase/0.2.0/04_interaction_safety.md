# 0.2.0 04 — 공개 버튼·확인 메뉴와 한국어 UI 안전

| 항목 | 내용 |
| --- | --- |
| 버전 | 0.2.0 |
| 단계 | 04 / 05 |
| 선행 조건 | 01~03단계의 실제 Discord 명령 연결 |
| 검증 호스트 | DiscordBotLXC |
| 상태 | IN_PROGRESS — 필수 인수 전 |

## 목표

- 버튼·선택 메뉴에서도 슬래시와 동일한 권한·확인·버전 검사를 강제한다.
- 사용자에게 변경 대상·범위·수량과 실패 이유를 짧은 한국어로 알린다.

## 추론 프로필 적용

[Jev API 전용 계약](../INFERENCE_PROFILES.md)을 따른다. 실제 자연어 판단은 `jev-api`만 사용하며 봇과 TLS 중계·영속 원장은 DiscordBotLXC에서 별도 계정으로 실행한다. 현재 배치는 [환경 계약](../ENVIRONMENT.md)을 따른다. `mock`은 지정 LXC의 격리 회귀 전용이다. 구조화 명령은 추론 없이 실행하고, API 장애가 기존 재생·슬래시·버튼을 막지 않게 한다.

## 로컬 코드 작업

로컬은 작성·읽기 검토만 한다. 모든 설치·정적 검사·시험·build·Discord 실행은 LXC에서 한다.

- custom ID에는 비밀 토큰 원문/대상 권한을 담지 않고 서버측 요청/메뉴 상태와 연결한다.
- 확인/취소 버튼은 actor/guild·60초 만료·consumed 상태·대상 버전을 검증하고 권한을 새로 조회한다.
- 일반 조회 버튼과 DJ 변경 버튼을 구분하되 공개 DJ 버튼 클릭 자체를 권한 증거로 사용하지 않는다.
- 검색/확인 메뉴 만료·대상 삭제·재시작·패널 삭제에 대한 오류 응답을 작성하고 이미 끝난 작업을 다시 실행하지 않는다.
- 목록/대기열 구분·동명 대상 선택·변경 수량·정책 override 도움말을 표시한다. 미구현 재생 패널에는 가짜 현재곡을 표시하지 않는다.

## 산출물

- 버튼/메뉴 dispatch·공통 정책 연결과 만료/재시작 처리 코드.
- 조회/변경/확인/충돌/미지원 한국어 응답 목록.
- 컴포넌트 요청 수명과 정보 노출 최소화 설계.

## LXC 검증

- DiscordBotLXC에서 실제 공개 DJ 버튼을 비DJ가 클릭하는 T-05를 수행한다.
- 타인 승인·동일 버튼 반복 클릭·만료 후 클릭·DJ 해제 후 승인·목록 버전 변경 후 승인을 검사한다.
- 긴 요청·Discord rate limit·메시지 삭제 상황을 mock으로 주입하고 접수/결과 중복과 불필요한 재전송을 확인한다.

## 통과 기준

- T-05에서 권한 거절과 변경 0건을 확인한다.
- 확인 한 번으로 여러 번 변경되거나 만료/역할/대상 변경을 우회하지 않는다.
- 실패·미구현 응답이 성공처럼 표시되지 않고 사용자가 재선택/재요청할 경로가 있다.

## 중단·후속 처리

- 컴포넌트 정책 우회가 발견되면 버튼 변경 기능을 닫고 공통 실행기 경로를 수정한다.
- 재생 패널·상태 갱신과 패널 삭제 뒤 재생 유지는 0.4.0에서 실제 세션과 연결한다.

## Jev API 전용 인수 범위

2026-09-27 사용자 결정에 따라 실제 제공자는 `jev-api` 하나다. [전용 계약](../INFERENCE_PROFILES.md)을 따른다. 과거 로컬 모델 시험은 보존 기록이며 이 단계의 선행 조건이나 출시 게이트가 아니다. 권한·확인·데이터·최대3단계/3 dispatch·전체12초/단계4초·실패 후 추가 전송0 규칙은 유지한다. hosted 내부 forward와 미공개 model revision은 null/unavailable로 남긴다.
