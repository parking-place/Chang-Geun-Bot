## 추론 프로필 적용

[Jev API 전용 계약](../INFERENCE_PROFILES.md)을 따른다. 실제 자연어 판단은 `jev-api`만 사용하며 봇과 TLS 중계·영속 원장은 DiscordBotLXC에서 별도 계정으로 실행한다. 현재 배치는 [환경 계약](../ENVIRONMENT.md)을 따른다. `mock`은 지정 LXC의 격리 회귀 전용이다. 구조화 명령은 추론 없이 실행하고, API 장애가 기존 재생·슬래시·버튼을 막지 않게 한다.

## 범위

- 슬래시·버튼·메뉴 접수, 실제 Discord ID/권한, 관리자 설정.
- fixture 기반 내부 검색과 DJ 목록 CRUD·복사·항목 편집.
- 요청자 결합 확인·컴포넌트 재검증·한국어 응답.
- T-01·02·03·05·06의 실제 Discord 인수와 T-10 이름 충돌 정책 선행 검증. 대기열 저장의 T-10 최종 시험은 0.4.0이다.

## 범위 밖과 후속

- 외부 URL/목록 메타데이터와 재생 소스 어댑터는 0.3.0에서 연결한다.
- 실제 음성·대기열·재생 패널은 0.3.0~0.4.0이며 지원 전에는 명시적으로 비활성이다.
- 자연어 실행·일반 호출어 모드는 0.6.0에서 Intent/권한 검증 뒤 활성화한다.
- 복사는 이 버전에서 제공하고 실제 카탈로그·충돌·가져오기·내보내기·되돌리기는 0.7.0에서 강화한다.

## 버전 종료 게이트

fixture 카탈로그로 실제 테스트 Discord 명령과 버튼이 동작하고 핵심 목록/권한/확인 시험을 통과해야 한다. mock만 통과한 경우 실제 Discord 인수는 미검증으로 남긴다. 자연어·실재생 완료를 주장하지 않으며 모든 실행 전 상태는 계획 / 미구현 / 미검증이다.

## Jev API 전용 인수 범위

2026-09-27 사용자 결정에 따라 실제 제공자는 `jev-api` 하나다. [전용 계약](../INFERENCE_PROFILES.md)을 따른다. 과거 로컬 모델 시험은 보존 기록이며 이 단계의 선행 조건이나 출시 게이트가 아니다. 권한·확인·데이터·최대3단계/3 dispatch·전체12초/단계4초·실패 후 추가 전송0 규칙은 유지한다. hosted 내부 forward와 미공개 model revision은 null/unavailable로 남긴다.
