- 상태: **계획 / 미구현 / 미검증**
- 선행 버전: [0.8.0](../0.8.0/README.md)의 장애·운영·복원 검증 완료.
- 명세 근거: [개발 명세 v1.3](../../CHANGGEUN_DEVELOPMENT_SPEC_v1.3.md) §11, §16~17, §19.
- 대상: `DiscordBotLXC`의 봇·별도 계정 중계. 테스트 봇·DB·서비스는 운영 컨텍스트와 분리한다.
- 로컬 범위: 후보 코드·시험 코드·증거 문서 작성. 설치·lint·빌드·시험은 지정 LXC에서만 수행한다.

## 범위

하나의 불변 후보 커밋에 `jev-api` 기능·보안·한국어 평가·경로별 성능·8시간 혼합 부하·복원 증거를 모은다. Jev API 프로필은 같은 소스·fixture·초기 snapshot·seed·안전 정책을 사용하되 DB/큐·원장·증거는 분리하고 순차 시험한다. 코드·모델/원격 버전·프롬프트·임계값·설정 변경이 필요하면 새 후보/설정 조합을 발급하고 영향받는 검증을 다시 수행한다.

최종 held-out runner는 Jev API 고정 프로필·독립 데이터/채점·격리 경로를 요구한다. 구현한 `korean-eval`의 개발37문장으로 최종200문장을 대체하지 않는다. `benchmark`·`soak`·`regression`·`restore`도 각각 실행하며 `--dry-run`과 `mock` 결과는 실제 제공자 인수 증거를 대체하지 않는다. 전환은 신규 접수 중지·drain·tombstone 보존·새 run/session 발급으로 수행한다.

## 버전 통과 조건

필수 T-01~T-20, N-01~N-36, P-01~P-12, O-01~O-08 및 B-01~B-12의 프로필 계약을 추적하며, 공통 안전·한국어 최소 200문장·1/2/3단계 경로별 최소 100회·최소 8시간 연속 혼합 재생·별도 장애 주입·복원·보안 항목이 Jev API에서 같은 후보의 원격 증거로 충족되어야 한다. 사용자 승인된 승인 음원·YouTube 링크/목록 관리 범위의 필수 기능이 미검증이면 1.0.0 승격을 차단한다. 직접 오디오 추출·전송은 1.0.0에서 제외하며 승인 음원과 혼동하지 않는다.
