# 1.0.3 Phase 3 — 동적 주시 정책과 요청·재생 수명

- 상태: **IN_PROGRESS — 개발 봇 적용·자동 회귀·사용자 부분 인수 통과, 전체 W 인수 미완료**
- 선행: [Phase 2](02_storage_and_migration.md)의 영속 revision/세대/변경 트랜잭션

## 진입 경로별 정책

| 경로 | 채널 판단 기준 |
| --- | --- |
| 여섯 `/주시` 관리 명령 | 등록 guild·일반 텍스트·접근 가능·최신 관리자 검사 |
| 일반 슬래시/버튼·멘션·`/부탁` | 기존 공통 텍스트/권한 정책 |
| `!!창근아` | 운영자 허용·본문 접근 준비·DB 서버 활성·등록된 정상 채널 + 기존 DJ/음성/확인 정책 |
| prefix에서 만들어진 후속 확인/메타데이터 등록 | 원 요청의 서버 검증 출처·세대·취소·만료를 상속 |

공통 실행기를 유지하면서 권한 조회가 진입 경로를 알 수 있게 한다. 기존 `ActionPlan.origin=natural_language`는 prefix·멘션·슬래시 자연어를 구분하지 못하므로 이것만 권한 근거로 사용하지 않는다. 어댑터가 생성하고 DB 원장에 묶은 요청 신원으로 prefix 권한을 증명한다. `.register` 자식 요청·확인 버튼·새 요청자 조작에도 출처를 임의 변경하지 못하게 한다. gateway/API1.2에 Discord 채널 설정이나 새 설정 변경 후보를 넣지 않는다.

## 접수와 변경 경합

1. 메시지 종류·guild·주시 정책을 검사한 뒤 정확한 접두어 파서를 적용한다. 미주시 메시지는 본문 로그·문맥·Jev·새 명령 DB 변경 없이 끝낸다. 일반 대화를 읽어 호출어를 찾아내거나 과거 메시지를 다시 읽지 않는다.
2. 접수 원장에 설정 revision·서버 활성 세대·채널 승인 세대를 결합한다. 각 Jev dispatch 전, 확인 승인과 공통 실행기 커밋 직전에 최신 상태를 검사한다. 기존에 저장만 하던 `policy_hash`에 실행 시 검증을 연결한다. revision/hash가 달라졌다면 최신 정책을 다시 평가하되, 해당 채널·활성 세대가 그대로 유효한 요청을 무관한 변경 때문에 취소하지 않는다.
3. 해당 채널 제거는 그 채널의 미커밋 prefix 요청/확인·시작 전 재생 승인을, 서버 끄기는 해당 서버의 prefix 전체를 무효화한다. 추가 또는 다른 채널의 제거는 무관한 진행 요청/기존 큐 승인을 유지한다. 관리자 변경 충돌에는 전체 revision, 실행 자격에는 채널 세대와 서버 활성 세대를 사용한다.
4. 설정 변경 트랜잭션과 명령 커밋의 순서를 기준으로 결과를 판정한다. 명령 커밋 전에 제거가 완료되면 변경0, 이미 완료된 곡/목록 편집은 자동 undo하지 않는다. Jev 취소 뒤 외부 계산이 끝나는 경우에도 추가 dispatch나 늦은 실행을 허용하지 않는다. 호출 예산은 환불하지 않는다.

## 시작 전 승인과 오디오 경합

`audio_admissions`에 prefix/슬래시/멘션 출처와 해당 세대를 결합하고, 제거·끄기 시 prefix 출처만 선별해 무효화한다. 미디어 준비 전/후와 실제 `voice.play` 시작 직전까지 검사한다. **설정 변경과 새 재생 시작은 같은 서버 단위 직렬화 경계**를 사용해 검사 직후 설정이 바뀌는 틈을 막는다. 이 잠금으로 오래 걸리는 추론·추출/FFmpeg 준비를 감싸지 않는다.

무효 항목은 큐에 남기고 조회에 `승인 만료`와 이유를 표시한다. 다음 항목 선택에서는 이를 제외한 첫 유효 항목을 재생하며, 만료된 항목 자체를 삭제하거나 미디어 실패 횟수로 세지 않는다. 시작 가능한 항목이 없으면 IDLE로 남는다. 이미 시작한 PLAYING/PAUSED 현재곡은 동일 스트림의 계속을 허용하되 새 반복/재시작에는 최신 승인이 필요하다. 새 DJ의 명시 재생 요청은 기존 항목을 중복 추가하지 않고 새 admission으로 재승인한다.

현재곡/큐/승인 원장의 효과를 분리해, 다른 채널 사용자나 일반 슬래시가 만든 항목을 함께 취소하지 않는다. 복구 뒤 새 epoch로 들어온 메시지만 처리하고 재등록/켜기로 예전 원문·확인·큐 승인을 부활시키지 않는다. 실제 권한 상실·채널 삭제에도 같은 무효화 규칙을 적용한다.

| ID | 필수 시험 |
| --- | --- |
| W-09 | 공통 text 목록 밖 신규 prefix 허용·기존 슬래시/멘션 범위 불변·가짜 origin/자식 요청 우회0 |
| W-10 | 첫/후속 Jev 판단·확인 대기·등록 자식·커밋 직전 제거/끄기: 미커밋 효과0·불필요 dispatch0 |
| W-11 | 준비 전/후/voice.play 직전 경합·무효 큐 유지와 자동 제외·현재곡 pause/resume·반복·다른 출처 보존 |
| W-12 | 채널 삭제/권한 상실/재등록/다시 켜기·재연결·복원 시 무효화된 세대/승인 실행0, 일반 슬래시 음악 제어 유지 |
