## 목표

0.0.0의 준비 증거와 위험 판단을 묶어 0.1.0 개발의 출발점을 고정한다.

## 추론 프로필 적용

[Jev API 전용 계약](../INFERENCE_PROFILES.md)을 따른다. 실제 자연어 판단은 `jev-api`만 사용하며 봇과 TLS 중계·영속 원장은 DiscordBotLXC에서 별도 계정으로 실행한다. 현재 배치는 [환경 계약](../ENVIRONMENT.md)을 따른다. `mock`은 지정 LXC의 격리 회귀 전용이다. 구조화 명령은 추론 없이 실행하고, API 장애가 기존 재생·슬래시·버튼을 막지 않게 한다.

## 로컬 코드 작업

- 범위·코드 구조·원격 실행 runbook·환경 manifest·타당성 결정을 검토하고 단계별 누락·미확정 입력의 책임을 지정한다.
- 0.1.0 도메인·DB·실행기 요구를 실제 fixture와 예상 오류 코드로 구체화한다. 외부 소스/모델 없이도 도메인 시험이 가능하게 한다.
- Git가 도입되면 코드 SHA로 기준선을 남긴다. 문서만 저장된 현재 상태에서 제품 VERSION이나 릴리스 태그를 미리 생성하지 않는다.
- STATUS의 각 단계에 실제 증거 링크·BLOCKED 사유를 연결하고 도메인 개발 진행 가능과 음성·run별 추론 게이트 차단을 구분한다.
- 01단계의 REVIEWED 문서 증거와 02~04단계의 VERIFIED 실행 증거를 구분해 기준선에 연결한다.

## 산출물

- 0.0.0 기준선 보고서, DiscordBotLXC의 봇·중계의 개발 진입점, 0.1.0 입력·fixture 목록.
- 0.3.0 소스/DAVE·0.5.0 API/모델·0.9.0 최종 평가로 이어지는 위험 추적표.

## LXC 검증

- Jev API의 필수 시험이 미실행·실패이면 해당 단계를 완료하지 않는다. mock·개발 소규모 시험으로 실제 품질·장시간 인수를 대체하지 않는다.
- 소스/설정 revision을 DiscordBotLXC의 봇·중계에서 비교하고 mock 준비/탐색 시험/제품 시험을 서로 구분하여 보고한다. provider/profile_id/비밀값 제외 config hash·독립 run_id·의존성·분리 DB/원장·evidence 경로를 기준선에 묶는다.
- 초기 전송/인증 probe를 정식 API 인수로, 음성 탐색을 0.3.0의 정식 DAVE/소스 gate로 표시하지 않는다.

설치·빌드·lint·타입검사·단위/mock 시험을 포함한 제품 실행은 위 LXC에서만 수행한다. 로컬은 코드/문서 작성과 읽기 검토만 한다. [증거 양식](../EVIDENCE_TEMPLATE.md)에 실제 revision·실행 서버·결과를 남긴다.

## 통과 기준

- [ ] 로컬 작성 → 원격 검증 → 증거 회수 루프를 재현할 수 있고 0.1.0에 필요한 LXC 도메인 시험 경로가 준비되어 있다.
- [ ] 막힌 기술을 PASS로 바꾸지 않고 관련 출시 게이트와 재검증 계획이 남아 있다.
- [ ] 01단계 문서 검토와 02~04단계의 필수 실행 증거가 있으며 NOT_RUN/SKIPPED/실패를 PASS로 표시하지 않았다.

## 중단·후속 처리

공통 개발 환경이 준비되지 않으면 0.0.0 전체 DONE을 보류한다. 선택 경로의 탐색 통과와 나머지 경로의 미검증 추적이 있으면 해당 경로의 독립 개발을 진행할 수 있지만, Jev API 공급자 인수를 완료한 것으로 취급하지 않는다. 기능 코드 초안 작성은 가능하지만 시험/기술 차단이 해소된 것으로 취급하지 않는다.

통과 후 [버전 목차](README.md)와 [STATUS](../STATUS.md)를 갱신한다. 계획 문서 작성만으로 이 단계를 완료 처리하지 않는다.

## Jev API 전용 인수 범위

2026-09-27 사용자 결정에 따라 실제 제공자는 `jev-api` 하나다. [전용 계약](../INFERENCE_PROFILES.md)을 따른다. 과거 로컬 모델 시험은 보존 기록이며 이 단계의 선행 조건이나 출시 게이트가 아니다. 권한·확인·데이터·최대3단계/3 dispatch·전체12초/단계4초·실패 후 추가 전송0 규칙은 유지한다. hosted 내부 forward와 미공개 model revision은 null/unavailable로 남긴다.
