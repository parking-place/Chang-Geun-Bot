## 목표

외부 목록과 저장 파일을 검증한 스냅샷으로 가져오고 데이터/지원 범위를 정확히 표시한다.

## 추론 프로필 적용

[Jev API 전용 계약](../INFERENCE_PROFILES.md)을 따른다. 실제 자연어 판단은 `jev-api`만 사용하며 봇과 TLS 중계·영속 원장은 DiscordBotLXC에서 별도 계정으로 실행한다. 현재 배치는 [환경 계약](../ENVIRONMENT.md)을 따른다. `mock`은 지정 LXC의 격리 회귀 전용이다. 구조화 명령은 추론 없이 실행하고, API 장애가 기존 재생·슬래시·버튼을 막지 않게 한다.

## 로컬 코드 작업

- 0.2.0 목록 복사를 확장하여 새 목록/entry ID·원본 독립·이름 충돌 정책을 회귀한다. 원본 링크·순서·운영자 메모 중심의 JSON 내보내기를 작성한다.
- 0.3.0 PlaylistImporter에 페이지 완료·최대 500항목·중복·비공개/삭제·부분 읽기 실패 구분과 재현 가능한 미리보기를 연결한다.
- 내보낸 JSON 가져오기의 schema/용량/형식/URL/서버 범위를 검사하고 불필요한 개인 ID/비밀값/서명 URL·hosted 키·내부 토큰·프로필 환경 설정이 들어가지 않게 한다. import가 실행 중인 추론 프로필이나 endpoint를 변경할 수 없도록 한다.
- 20곡 이상·기존 목록 덮어쓰기 확인 정책과 확인 시 이름/대상 version/최대 수량 재검사를 공통 실행기에 연결한다.
- 일부 실패 시 성공 항목만 반영할지 DJ가 선택하게 한다. 결과는 가져온 시점의 snapshot이며 자동 동기화하지 않음을 표시한다.

## 산출물

- JSON schema·export/import 서비스·외부 페이지 미리보기 UI·복사/가져오기 감사 기록.
- P-07~08 및 악성 파일/URL/부분 실패 fixture.

## LXC 검증

- P-07: 페이지 누락/할당량/삭제 영상/중복/500 상한/부분 성공 동의를 DiscordBotLXC에서 검증한다.
- P-08: 내보내기 → 빈 테스트 목록 가져오기의 순서/참조 보존·복사 독립·secret 비포함·덮어쓰기 확인을 검증한다.
- 외부 연결/DB 장애에서 자동 재시도로 중복 반영되지 않으며 내부 조회/재생은 유지되는지 확인한다.

설치·빌드·lint·타입검사·단위/mock 시험을 포함한 제품 실행은 위 LXC에서만 수행한다. 로컬은 코드/문서 작성과 읽기 검토만 한다. [증거 양식](../EVIDENCE_TEMPLATE.md)에 실제 revision·실행 서버·결과를 남긴다.

## 통과 기준

- [ ] 전체 페이지를 읽지 못한 결과를 전체 목록이라고 표시하지 않고 대량 작업은 필수 확인 후 반영한다.
- [ ] 원본/사본이 독립적이며 파일에 비밀값·일시 재생 URL·불필요한 개인 원문이 없다.
- [ ] 필수 시험의 실행 증거가 있으며 NOT_RUN/SKIPPED/실패를 PASS로 표시하지 않았다.

## 중단·후속 처리

외부 정책/할당량 변경은 공식 자료와 결정 기록으로 갱신한다. 검증되지 않은 쿠키/OAuth/원격 목록 수정으로 우회하지 않는다.

통과 후 [버전 목차](README.md)와 [STATUS](../STATUS.md)를 갱신한다. 계획 문서 작성만으로 이 단계를 완료 처리하지 않는다.

## Jev API 전용 인수 범위

2026-09-27 사용자 결정에 따라 실제 제공자는 `jev-api` 하나다. [전용 계약](../INFERENCE_PROFILES.md)을 따른다. 과거 로컬 모델 시험은 보존 기록이며 이 단계의 선행 조건이나 출시 게이트가 아니다. 권한·확인·데이터·최대3단계/3 dispatch·전체12초/단계4초·실패 후 추가 전송0 규칙은 유지한다. hosted 내부 forward와 미공개 model revision은 null/unavailable로 남긴다.
