## 목표

편집 복구와 유지보수 기능을 안전하게 완성하고 P1 확장으로 기존 음악봇/자연어 정책이 깨지지 않는지 검증한다.

## 추론 프로필 적용

[Jev API 전용 계약](../INFERENCE_PROFILES.md)을 따른다. 실제 자연어 판단은 `jev-api`만 사용하며 봇과 TLS 중계·영속 원장은 DiscordBotLXC에서 별도 계정으로 실행한다. 현재 배치는 [환경 계약](../ENVIRONMENT.md)을 따른다. `mock`은 지정 LXC의 격리 회귀 전용이다. 구조화 명령은 추론 없이 실행하고, API 장애가 기존 재생·슬래시·버튼을 막지 않게 한다.

## 로컬 코드 작업

- change_events 역변경은 목록/큐 편집에 한정하고 변경 후 대상 version이 일치할 때만 적용한다. 오디오 되감기/외부 실행 취소를 주장하지 않는다.
- 논리 삭제 목록의 기본 30일 보존·복원명 충돌·이름 재사용·사용자/외부 데이터 삭제의 우선순위를 작성한다.
- 재생 불가곡 점검에는 확인 시각·availability·재시도 한계를 두고 목록에서 자동 삭제하지 않는다. 최근 재생 제외는 실제 play_history로 계산한다.
- 모든 새 action에 인자·DJ/관리자·확인·상태 전제·오류 코드를 등록하고 슬래시/버튼/자연어 공통 실행기를 검토한다.
- P-01~12 결과와 기존 T/N의 영향 회귀를 묶어 0.8.0 운영 안정화의 입력 manifest를 작성한다.

## 산출물

- 되돌리기·목록 복원·불가곡 점검 명령/서비스·보존 정책·도움말.
- P-09~12와 0.7.0 통과 보고서, 기존 회귀 결과.

## LXC 검증

- P-09~10: 편집 뒤 다른 DJ가 수정한 경우 역변경 거절·동일 version에서 1회 undo·복원명 충돌/보존 만료를 DiscordBotLXC에서 검증한다.
- P-11~12: 불가곡 목록 보존·조회 점검 중 재생 유지·최근 7일 제외·새 action의 모든 입력 권한/확인을 시험한다.
- DiscordBotLXC의 봇·중계에서 Jev API의 전체 T/N 영향 회귀를 수행하고 NL 단계/판단·질문/provider_calls/확인 정책이 새 기능에서도 유지되는지 확인한다.
- B-01~12 중 이 버전의 선택·전환·비밀값·설정 비교 격리·증거 회귀를 시험 추적표에 연결한다. `regression` suite에서 Jev API의 독립 DB/큐를 사용하고 동일 실제 Discord 변경을 shadow 실행으로 두 번 반영하지 않는다.

설치·빌드·lint·타입검사·단위/mock 시험을 포함한 제품 실행은 위 LXC에서만 수행한다. 로컬은 코드/문서 작성과 읽기 검토만 한다. [증거 양식](../EVIDENCE_TEMPLATE.md)에 실제 revision·실행 서버·결과를 남긴다.

## 통과 기준

- [ ] P-01~12 전건과 run별 필수 자연어 회귀 증거가 있으며 새 기능도 권한/중복/버전/확인 계약을 준수한다. 구조화 시험은 공통으로 재사용할 수 있지만 한 공급자의 성공을 다른 공급자의 PASS로 기록하지 않는다.
- [ ] 복원/undo가 오래된 변경을 덮어쓰지 않고 미검증 외부 재생을 지원 완료로 안내하지 않는다.
- [ ] 필수 시험의 실행 증거가 있으며 NOT_RUN/SKIPPED/실패를 PASS로 표시하지 않았다.

## 중단·후속 처리

P1을 선택 사항이라며 계획에서 제외하지 않는다. 범위 변경은 명세 결정에 남기고 미충족 기능을 분리하여 출시 차단 상태를 갱신한다.

통과 후 [버전 목차](README.md)와 [STATUS](../STATUS.md)를 갱신한다. 계획 문서 작성만으로 이 단계를 완료 처리하지 않는다.

## Jev API 전용 인수 범위

2026-09-27 사용자 결정에 따라 실제 제공자는 `jev-api` 하나다. [전용 계약](../INFERENCE_PROFILES.md)을 따른다. 과거 로컬 모델 시험은 보존 기록이며 이 단계의 선행 조건이나 출시 게이트가 아니다. 권한·확인·데이터·최대3단계/3 dispatch·전체12초/단계4초·실패 후 추가 전송0 규칙은 유지한다. hosted 내부 forward와 미공개 model revision은 null/unavailable로 남긴다.
