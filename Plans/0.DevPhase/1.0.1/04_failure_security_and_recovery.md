## 작업과 계약

- 오류를 URL/지원 불가·권한/제한·일시 네트워크·만료·decode/음성·자원 부족으로 분류한다. 단일 영상이 처음부터 지원 불가이면 큐 변경 전에 거절한다. 여러 곡 목록은 제외 미리보기 후 확인한 부분만 추가하고, 이미 대기 중인 항목이 접근 불가로 바뀌면 그 항목만 실패 처리한다.
- 일시 실패·만료의 재해석/재접속은 한 항목에서 합산 추가1회로 제한한다. HTTP/extractor/FFmpeg 옵션의 기본 retry가 이 상한을 넘지 않게 한다. 이미 재생된 음원을 자동으로 처음부터 반복하지 않으며 중도 단절은 실패/다음 곡으로 처리한다. 3곡 연속 실패 시 멈추고 안내한다.
- 정지·스킵·퇴장·강제퇴장·서비스 종료·권한 상실은 해당 entry의 요청/승인 소유권에 연결된 대기/해석/stream 작업을 취소한다. 정지·스킵·교체 등 외부 변경으로 작업 소유권이 무효화되면 재시도도 금지한다. 상태기계가 허용한 재시도의 새 generation은 같은 entry·작업과 남은 시도/시간 예산에 귀속시킨다. 총 준비25초와 누적 해석15초/startup10초를 재시도로 초기화하지 않는다. 프로세스 그룹 terminate 후 최대2초 안에 회수되지 않으면 kill하고 리소스를 정리한다.
- `READING/RESOLVING` 등 중간 상태와 현재곡/큐 영속성·실행 불명 effect를 재시작 복구 계약에 반영한다. 부팅 시 자동입장·재생·이전 stream URL 재사용 금지. 명시 새 요청에서만 fresh resolve한다.
- 2CPU/2GiB 봇 LXC의 실제 서비스 메모리/CPU/FD/child 수·버퍼·디스크 쓰기를 측정한다. resolver 하위 프로세스도 기존 cgroup 한도에 포함한다. 추출 때문에 Discord heartbeat·슬래시·현재 오디오가 굶지 않도록 실행을 분리한다.
- raw 추출 결과·stderr·미디어 URL 없이 source type/오류 종류/resolve/startup 시간·정리 결과를 계측한다. 외부 키·쿠키 수집을 추가하지 않는다. 기능 off/후보 rollback은 저장된 YouTube 참조를 삭제하지 않고 재생만 비활성화한다.
