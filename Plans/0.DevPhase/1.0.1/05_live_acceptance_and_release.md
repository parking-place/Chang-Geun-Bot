## 고정 후보와 시험

source/lock/schema·source adapter·extractor/JS/EJS/FFmpeg 버전·소스 한도·CDN/egress 정책·Jev 설정을 manifest에 고정한다. 실제 플랫폼 요청/반환 정보를 기록하되 signed URL/쿠키/키는 제외한다. API로 조회 가능한 영상이라고 무조건 재생 가능으로 분류하지 않는다.

- **Y-17 실제 인수:** 매핑 없는 지원 공개 영상20개 이상에서 URL·검색 선택·저장 목록·Shorts·다양한 길이/형식을 포함해 최소100회 재생 시작/전환을 시험한다. 준비5회도 요청 한도에 포함한다. 공식 검색/소스해석/음성연결/첫오디오를 따로 측정하고 성공률≥95%, 정상 무대기 준비된 음성 연결에서 접수→첫오디오 p95≤10초를 초기 목표로 판정한다. 외부 제한/timeout을 표본에서 빼지 않고, 의도적으로 고른 제한 영상의 거절 시험은 별도 표로 기록한다. 사용자 청취·제어는 실제 Discord 시험 증거를 남긴다.
- **Y-18 장시간/출시:** YouTube와 승인 음원 혼합·곡 전환·구조화/기존 자연어 명령을 포함한 연속8시간 실제 재생, resource/재시작/오디오 단절·영속성·예산을 기록한다. 장애 주입으로 끊긴 시간을 이어 붙이지 않는다. 단계적 배포→최소 smoke→기능 off→이전 고정 후보 rollback→명시 복구를 검증한다.

20개/100회/95%/10초는 제품의 인수 목표이며 외부 서비스 SLA가 아니다. 실패를 숨기거나 성공한 곡만 골라 출시하지 않는다. 독립 품질 기준은 변경 영향에 맞춰 적용하며 prompt/후보를 바꾸면 Jev 한국어 회귀와 독립200문장·단계 경로 성능 증거도 갱신한다.

## 완료 기준

Y-01~18과 영향받는 기존 기능·권한·취소·DB/백업 시험에 실제 증거가 연결되고, 플랫폼 조건/전송 방식의 채택 근거가 해결되어야 한다. 최종 설치 후보와 시험 후보가 일치하며 기능을 꺼도 기존 음원/목록/데이터가 보존되어야 한다.

도움말에는 지원 공개 VOD·길이 상한·제한 영상 안내·검색 선택·재생목록 가져오기·시작 위치/라이브 미지원과 실제측정값을 반영한다. 검증 전 “모든 YouTube 재생 가능”이라고 표시하지 않는다. 버전 상태·출시 기록·VERSION/태그는 계획이 아니라 실제 인수·배포 뒤 갱신한다.

후속 [1.0.2](../1.0.2/README.md)의 접두어 파서·허용채널·권한 시험은 독립 개발할 수 있다. YouTube 자연어 재생의 최종 인수는 검증된 1.0.1 소스 경로를 사용한다.
