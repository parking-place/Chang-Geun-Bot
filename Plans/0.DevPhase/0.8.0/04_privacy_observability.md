# 0.8.0 Phase 4 — 관측·로그·개인정보

- 버전: `0.8.0`
- 단계: `4 / 5`
- 선행: [Phase 3](03_backup_restore.md) 백업·만료 정책 검증 통과.
- 검증 호스트: `DiscordBotLXC`의 봇·별도 계정 중계
- 상태: **IN_PROGRESS — 필수 인수 전**
- 추론 계약: [프로필 선택·시험 실행](../INFERENCE_PROFILES.md), [개발 명세 v1.3](../../CHANGGEUN_DEVELOPMENT_SPEC_v1.3.md), 내부 API schema `1.2`.

## 목표

- 안전한 구조화 로그로 명령·추론·재생·저장 실패를 구분한다.
- 보존·삭제·백업 복원까지 개인정보 정책을 일관되게 적용한다.

## 로컬 코드 작업

- request/command ID·run_id·provider·profile_id·설정 hash, 결과/오류 코드, 판단·질문 수·`provider_calls`, 조기 종료·3단계 사유를 기록한다.
- queue/inference/total 시간·잔여 deadline·prompt version을 기록한다. hosted는 외부 요청 지연·반환 모델/API 버전·측정시각·429/요금 한도를 분리 기록한다. 원격 계산 시간·실행 횟수를 추정 실측값으로 채우지 않는다.
- 구조화 명령은 stage_count=0, 자연어는 실제 1~3이며 자유로운 사고 과정은 수집하지 않는다.
- 토큰·쿠키·서명 URL·개인 원문을 필터링하고 운영 지표에서 사용자 ID를 제외한다.
- 운영 로그 7일·변경 감사 90일·선택 원문 72시간과 서버·사용자 삭제 경로를 작성한다.

## 산출물

- 명세 §14.3·§16.3에 대응하는 로그 스키마·내부 metrics·보존 및 삭제 작업.
- 원문 수집 기본 OFF와 선택 수집 안내·익명화 평가 반입 절차. hosted 시험은 합성/익명 fixture와 최소 후보·문맥만 송신하며 외부 보존·학습 이용·삭제 정책은 확인 전 미확정으로 표시한다. 내부 로그 보존기간이 공급자 삭제를 보장하지 않는다.
- 디스크 여유·백업 시각·마지막 복원·OOM·재시작을 확인하는 운영 점검 문서.

## LXC 검증

- `DiscordBotLXC`: 검색·재생·DB·권한 실패의 로그 분류와 비밀값 제거를 검증한다.
- `DiscordBotLXC의 중계`: Jev API의 단계별 시간·provider_calls 누계·원장 재사용·취소 결과 폐기 지표를 검증한다. hosted forward 필드가 0이나 가짜 관측값으로 채워지지 않는지와 `JEV_HOSTED_API_KEY`/내부 토큰 비노출을 확인한다.
- DiscordBotLXC의 봇·중계: 시험용 민감 문자열로 정상·오류·traceback·응답 경로의 노출을 확인한다.
- 보존기한 경과·사용자 삭제·복원 후 재삭제를 시험 데이터로 검증한다.
- 시험·lint·빌드·로그 검색 실행은 원격에서만 수행하고 증거는 비식별화한다.

## 통과 기준

- 토큰·서명 URL·개인 원문이 기본 로그와 사용자 오류에 나타나지 않는다.
- 서로 다른 지표를 합산해 단일 PASS나 성능값으로 표시하지 않는다.
- 삭제·보존기한이 활성 데이터와 복원 절차에 반영된다.
- 관측을 위해 세 번째 LXC나 필수 대시보드를 요구하지 않는다.

## 중단·후속 처리

- 비밀 노출이 확인되면 해당 로깅 경로를 차단하고 실제 노출 범위를 조사한다.
- 필요하면 노출된 비밀값을 교체한 뒤 재시험하며 공개 증거에 원문을 붙이지 않는다.
- 로그 누락·삭제 실패는 수정하고 Phase 5 운영 훈련의 확인 항목에 추가한다.

## Jev API 전용 인수 범위

2026-09-27 사용자 결정에 따라 실제 제공자는 `jev-api` 하나다. [전용 계약](../INFERENCE_PROFILES.md)을 따른다. 과거 로컬 모델 시험은 보존 기록이며 이 단계의 선행 조건이나 출시 게이트가 아니다. 권한·확인·데이터·최대3단계/3 dispatch·전체12초/단계4초·실패 후 추가 전송0 규칙은 유지한다. hosted 내부 forward와 미공개 model revision은 null/unavailable로 남긴다.
