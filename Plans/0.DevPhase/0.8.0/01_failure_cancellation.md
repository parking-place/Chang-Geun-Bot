# 0.8.0 Phase 1 — 장애·취소·복구 정책

- 버전: `0.8.0`
- 단계: `1 / 5`
- 선행: [0.7.0 완료](../0.7.0/README.md), 기존 명령·음성·Jev 상태 계약.
- 검증 호스트: `DiscordBotLXC`의 봇·별도 계정 중계
- 상태: **IN_PROGRESS — 필수 인수 전**
- 추론 계약: [프로필 선택·시험 실행](../INFERENCE_PROFILES.md), [개발 명세 v1.3](../../CHANGGEUN_DEVELOPMENT_SPEC_v1.3.md), 내부 API schema `1.2`.

## 목표

- 명세 §13의 장애표를 실행 상태·사용자 안내·복구 동작으로 연결한다.
- 늦은 결과가 취소·만료·강제 퇴장 뒤 실행되지 않도록 한다.

## 로컬 코드 작업

- 공통 12초 deadline·최대 3단계 판단/질문·`provider_calls ≤ 3`을 유지한다. 프로필 자동 fallback, SDK/HTTP 숨은 retry, 3단계 뒤 새 ID 자동 재시도를 금지한다.
- `jev-api`는 연결 취소가 원격 계산/청구 취소를 증명하지 않음을 기록한다. 전송 여부가 불명인 timeout은 사용한 예산을 환불하지 않고 재호출하지 않으며 terminal unknown/tombstone으로 남긴다.
- `/퇴장`·명시적 퇴장·관리자 강제 퇴장에서 generation을 갱신하고 재연결을 중단한다.
- DB 쓰기 실패·권한 조회 실패를 거짓 성공 없이 처리하고 메모리·DB 상태를 맞춘다.

## 산출물

- 오류 코드·사용자 안내·상태 전이를 연결한 장애 정책과 테스트 코드.
- 음성 재연결 최대 3회, 곡 재시도 최대 1회, 연속 실패 3곡 중단의 공통 정책.
- 공통 원장 불명 상태의 명령 미실행 처리, provider별 취소·watchdog 운영 조건과 중지/drain 절차. 설정·후보 변경 전 기존 요청을 종료·불명 처리하고 새 run/session을 발급하되 tombstone을 삭제하지 않는다.

## LXC 검증

- `DiscordBotLXC의 중계`: Jev API에서 대기 초과·기한 초과·요청 취소·원장 불일치·provider/profile_id/config_hash 불일치를 주입한다. hosted에는 네트워크/TLS·401·429·5xx·요금 한도 및 전송 후 응답 유실을 추가한다.
- `DiscordBotLXC`: 검색 중 퇴장·강제 퇴장·권한 조회 실패·디스크 부족을 주입한다.
- DiscordBotLXC의 봇·중계: 추론을 중단하는 동안 슬래시·버튼·기존 음성 재생이 계속되는지 확인한다.
- 제어된 fixture로 늦은 응답·중복 요청을 gateway에 재수신시켜 명령 변경과 `provider_calls`가 증가하지 않는지 확인한다.
- 모든 실행·설치·lint·빌드·시험은 원격에서 수행하고 SHA와 오류 시각을 남긴다.

## 통과 기준

- 취소·만료·권한 실패·강제 퇴장 후 변경과 재입장이 0건이다.
- hosted의 원격 종료 여부는 관측 불가로 남기고 늦은 결과 폐기·추가 dispatch 0건을 검증한다. hosted 원격 계산 종료를 PASS로 표시하지 않는다.
- DB 실패가 성공으로 응답하지 않고 커밋된 참조·목록·큐는 보존된다.
- 실제 실패와 안내·로그 오류 코드가 일치한다.

## 중단·후속 처리

- 늦은 실행·무한 재시도·슬롯 중복이 있으면 후속 운영 검증을 중단한다.
- 구현을 수정한 새 커밋으로 해당 장애와 인접 정상 경로를 원격 재시험한다.
- PASS 증거를 [공통 양식](../EVIDENCE_TEMPLATE.md)에 남긴 뒤 Phase 2로 진행한다.

## Jev API 전용 인수 범위

2026-09-27 사용자 결정에 따라 실제 제공자는 `jev-api` 하나다. [전용 계약](../INFERENCE_PROFILES.md)을 따른다. 과거 로컬 모델 시험은 보존 기록이며 이 단계의 선행 조건이나 출시 게이트가 아니다. 권한·확인·데이터·최대3단계/3 dispatch·전체12초/단계4초·실패 후 추가 전송0 규칙은 유지한다. hosted 내부 forward와 미공개 model revision은 null/unavailable로 남긴다.
