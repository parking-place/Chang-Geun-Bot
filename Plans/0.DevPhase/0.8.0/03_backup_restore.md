# 0.8.0 Phase 3 — 일관성 백업과 분리된 복원

- 버전: `0.8.0`
- 단계: `3 / 5`
- 선행: [Phase 2](02_systemd_lifecycle.md) 서비스·저장 경로 확정.
- 검증 호스트: `DiscordBotLXC`의 봇·별도 계정 중계
- 상태: **IN_PROGRESS — 필수 인수 전**
- 추론 계약: [프로필 선택·시험 실행](../INFERENCE_PROFILES.md), [개발 명세 v1.3](../../CHANGGEUN_DEVELOPMENT_SPEC_v1.3.md), 내부 API schema `1.2`.

## 목표

- 살아 있는 SQLite의 일관성 백업과 실제 복원 가능성을 확보한다.
- 두 지정 LXC 안의 분리된 시험 컨텍스트에서 운영 데이터 덮어쓰기 없이 복원한다.

## 로컬 코드 작업

- SQLite Online Backup API 또는 검증한 동등 방식으로 DB 복사본을 만든다.
- 앱·내부 API schema `1.2`·의존성·provider/profile_id/config_hash·프롬프트/임계값·정책을 백업 manifest에 연결한다. hosted는 API 버전/반환 모델/측정시각/고정 불가 한계를 기록한다.
- 봇 DB와 공통 gateway 영속 원장의 백업·복구 범위를 분리하고 run별 원장·tombstone을 보존한다. 프로필 변경·복원으로 불명 요청을 새 요청으로 재실행하지 않는다.
- 일일 7개·주간 4개 보존, 노드 밖 복사본 확인과 실패 알림을 작성한다.
- 복원 후 확인 토큰 무효화·자동 입장 및 재생 금지·보존기한 만료 삭제를 적용한다.

## 산출물

- 백업 코드·보존 설정·검증 절차와 별도 암호화·접근통제 대상의 비밀값 관리 문서.
- Jev API에서 분리된 DB/원장·venv·시험 service·테스트 토큰을 사용하는 복원 runbook. 원본 snapshot과 복원 경로를 기록하고 설정 비교 시험이 같은 운영 DB를 중복 변경하지 않게 한다.
- RPO 24시간·RTO 60분 목표를 측정하는 복원 기록 양식.

## LXC 검증

- `DiscordBotLXC`: 쓰기 중 백업하고 복사본 무결성·곡 순서·큐·DJ 설정을 검증한다.
- `DiscordBotLXC의 중계`: Jev API의 분리된 원장 복원에서 중복·재시작 불명 요청이 추가 dispatch되지 않는지 검증한다. 이전 프로필의 tombstone도 보존되며 hosted 키는 백업 manifest에 포함하지 않는다.
- 원본과 다른 시험 경로·계정 컨텍스트로 복원하고 운영 DB·운영 음성 접근을 차단한다.
- 노드 밖 백업 수신·조회 가능성, 손상 백업 거절, 삭제 정책 반영을 확인한다.
- 모든 복원 실행은 DiscordBotLXC의 봇·중계 안에서 수행하고 세 번째 LXC를 필수 전제로 두지 않는다.

## 통과 기준

- 활성 DB 파일 하나를 단순 복사하는 백업에 의존하지 않는다.
- 복원한 데이터·설정·순서가 일치하고 확인 토큰과 자동 재생이 비활성이다.
- 실제 노드 밖 복사본과 복원 소요시간으로 RPO·RTO 목표 충족 여부를 기록한다.
- hosted는 공급자 모델/버전 고정 가능 여부와 복원 시 변경 여부를 명시하며 원격 모델 재현성을 보장한다고 기록하지 않는다.

## 중단·후속 처리

- 외부 백업 저장소 미정·무결성 실패·복원 불가이면 완료 처리하지 않는다.
- RPO·RTO 미달은 원인·복구 조건·재시험 일정으로 남기고 출시 게이트를 보류한다.
- 기존 운영 DB·볼륨·LXC를 덮어쓰거나 삭제하지 않고 Phase 4로 증거를 전달한다.

## Jev API 전용 인수 범위

2026-09-27 사용자 결정에 따라 실제 제공자는 `jev-api` 하나다. [전용 계약](../INFERENCE_PROFILES.md)을 따른다. 과거 로컬 모델 시험은 보존 기록이며 이 단계의 선행 조건이나 출시 게이트가 아니다. 권한·확인·데이터·최대3단계/3 dispatch·전체12초/단계4초·실패 후 추가 전송0 규칙은 유지한다. hosted 내부 forward와 미공개 model revision은 null/unavailable로 남긴다.
