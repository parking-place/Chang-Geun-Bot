## 목표

- DiscordBotLXC의 실제 환경에서 DAVE 지원 음성 입장·오디오 전송·재연결을 확인한다.
- 라이브러리 지원 선언과 실제 사용 가능한 재생 경로를 구분한다.

## 추론 프로필 적용

[Jev API 전용 계약](../INFERENCE_PROFILES.md)을 따른다. 실제 자연어 판단은 `jev-api`만 사용하며 봇과 TLS 중계·영속 원장은 DiscordBotLXC에서 별도 계정으로 실행한다. 현재 배치는 [환경 계약](../ENVIRONMENT.md)을 따른다. `mock`은 지정 LXC의 격리 회귀 전용이다. 구조화 명령은 추론 없이 실행하고, API 장애가 기존 재생·슬래시·버튼을 막지 않게 한다.

## 로컬 코드 작업

로컬은 작성·읽기 검토만 한다. 의존성 설치·검사·시험·build·음성 probe는 LXC에서 실행한다.

- 시험 전용 probe/어댑터 소스를 작성하고 테스트 guild·허용 음원·짧은 실행·명시적 종료 범위로 제한한다.
- 배포 시 공식 문서 기준으로 DAVE 지원 Discord 라이브러리·davey 등 음성 의존성과 잠금 파일을 정한다. 설치/빌드는 LXC에서만 수행한다.
- 봇 Connect/Speak·채널 접근·필요 Intent를 최소 권한으로 정의하고 Administrator를 기본 요구하지 않는다.
- UDP/NAT·오디오 변환·암호화 협상·연결/재연결 오류를 진단하는 최소 로그를 작성한다. 임시 주소·토큰·프롬프트 원문은 제외한다.
- 시험 음원을 실제 전송하되 제품 /재생 완성이나 유튜브 직접 재생 완료로 보고하지 않는다.

## 산출물

- 음성 의존성 pin/lock 소스와 제한된 실재생 probe.
- DAVE/UDP·입장/전송/재연결/퇴장 확인 항목.
- 환경·CPU/RAM·음성 버전·암호화 상태·수신 확인·오류 결과 증거 양식.

## LXC 검증

- DiscordBotLXC에서 의존성 설치/빌드와 실제 테스트 음성채널 DAVE 입장·전송·퇴장을 실행한다.
- 허용된 별도 음원 수신·곡 종료 콜백·일시 네트워크 단절 후 재연결·명시적 퇴장을 시험한다.
- 실제 UDP 왕복과 최소 Discord 권한을 확인한다. 추측한 고정 UDP 포트 하나로 성공을 판단하지 않는다.

## 통과 기준

- DAVE 사용·실제 수신·정상 종료·재연결 결과가 실측 증거로 남는다.
- 사용 라이브러리/의존성 버전과 시험 음원 권한 근거가 기록된다.
- probe PASS는 기술 소스 gate이며 T-11~20 제품 시나리오 PASS는 0.4.0에서 별도로 수행한다.

## 중단·후속 처리

- DAVE·권한·UDP·수신 검증 실패 시 0.4.0 실재생 활성화를 중단한다.
- 실행 경로 변경은 결정 기록에 이유/영향/검증 결과를 남기고 변경된 경로를 LXC에서 다시 검증한다.

## Jev API 전용 인수 범위

2026-09-27 사용자 결정에 따라 실제 제공자는 `jev-api` 하나다. [전용 계약](../INFERENCE_PROFILES.md)을 따른다. 과거 로컬 모델 시험은 보존 기록이며 이 단계의 선행 조건이나 출시 게이트가 아니다. 권한·확인·데이터·최대3단계/3 dispatch·전체12초/단계4초·실패 후 추가 전송0 규칙은 유지한다. hosted 내부 forward와 미공개 model revision은 null/unavailable로 남긴다.
