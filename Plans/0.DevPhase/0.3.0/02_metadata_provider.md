## 목표

- 실제 허용 URL에서 곡 참조를 등록하고 메타데이터의 출처·갱신 상태를 보존한다.
- 외부 입력의 모호함·실패·할당량을 목록 변경과 분리한다.

## 추론 프로필 적용

[Jev API 전용 계약](../INFERENCE_PROFILES.md)을 따른다. 실제 자연어 판단은 `jev-api`만 사용하며 봇과 TLS 중계·영속 원장은 DiscordBotLXC에서 별도 계정으로 실행한다. 현재 배치는 [환경 계약](../ENVIRONMENT.md)을 따른다. `mock`은 지정 LXC의 격리 회귀 전용이다. 구조화 명령은 추론 없이 실행하고, API 장애가 기존 재생·슬래시·버튼을 막지 않게 한다.

## 로컬 코드 작업

로컬은 작성·읽기 검토만 한다. 의존성 설치·검사·시험·build·음성 probe는 LXC에서 실행한다.

- 허용 도메인·URL 길이·리다이렉트·영상/목록 ID·접근 대상 검증을 작성한다. 임의 내부 주소/파일/명령 실행 입력을 거절한다.
- 영상 ID+목록 ID URL은 곡 한 개/목록 전체 선택을 받고 시작 시각은 처음부터 재생할지 확인한다. 초기 구간 재생은 제공하지 않는다.
- 원제목·게시 채널·길이·fetched_at/refresh_due_at·availability를 수집하고 운영자 표기와 분리 저장한다.
- 실행 시점 정책에 맞는 캐시 갱신/삭제·API quota/시간제한·비공개/삭제/지원불가 응답을 작성한다. 무기한 캐시를 기본으로 하지 않는다.
- 내부 정확 일치를 우선하고 외부 검색을 제공한다면 제한된 결과를 선택 메뉴로 반환한다. 전체 목록 가져오기 활성화는 0.7.0 후속으로 유지한다.

## 산출물

- URL validator·MetadataProvider와 허용 검색 제공자 코드.
- 캐시 갱신·가용성·할당량·부분 실패 오류 계약.
- 외부 목록 pagination/수량/실패 미리보기의 0.7.0 연결 인터페이스.

## LXC 검증

- DiscordBotLXC에서 provider mock·입력/리다이렉트 단위시험과 허용된 실제 메타데이터 연동 시험을 수행한다.
- 시간표시·영상+목록 혼합·삭제/비공개 영상·유사 후보·API 제한·타임아웃을 검사한다.
- 메타데이터 등록 후 audio 미지원 상태가 유지되고 내부 카탈로그 조회는 외부 서비스 장애 중에도 가능한지 확인한다.

## 통과 기준

- 0.2.0 fixture와 동일한 곡/목록 계약으로 실제 메타데이터가 연결된다.
- 선택하지 않은 목록 전체·검색 첫 결과·시작 시각이 자동 적용되지 않는다.
- API 실패가 부분 목록 전체 성공 또는 재생 가능으로 표시되지 않는다.

## 중단·후속 처리

- 입력 검증 우회·원본/운영자 출처 혼동·자동 대량 등록이면 해당 경로를 닫고 수정한다.
- 실제 외부 목록 가져오기·파일 import/export·20곡 이상 확인은 0.7.0에서 완성한다.

## Jev API 전용 인수 범위

2026-09-27 사용자 결정에 따라 실제 제공자는 `jev-api` 하나다. [전용 계약](../INFERENCE_PROFILES.md)을 따른다. 과거 로컬 모델 시험은 보존 기록이며 이 단계의 선행 조건이나 출시 게이트가 아니다. 권한·확인·데이터·최대3단계/3 dispatch·전체12초/단계4초·실패 후 추가 전송0 규칙은 유지한다. hosted 내부 forward와 미공개 model revision은 null/unavailable로 남긴다.
