## 목표

- 요청자가 허용된 음성채널만 선택하도록 하고 /입장은 연결만 수행한다.
- 명시적 퇴장·오래된 연결 완료가 재입장/재생으로 이어지지 않게 한다.

## 추론 프로필 적용

[Jev API 전용 계약](../INFERENCE_PROFILES.md)을 따른다. 실제 자연어 판단은 `jev-api`만 사용하며 봇과 TLS 중계·영속 원장은 DiscordBotLXC에서 별도 계정으로 실행한다. 현재 배치는 [환경 계약](../ENVIRONMENT.md)을 따른다. `mock`은 지정 LXC의 격리 회귀 전용이다. 구조화 명령은 추론 없이 실행하고, API 장애가 기존 재생·슬래시·버튼을 막지 않게 한다.

## 로컬 코드 작업

로컬은 작성·읽기 검토만 한다. 의존성 설치·검사·시험·build·음성 probe는 LXC에서 실행한다.

- 채널 선택은 명시 ID/메뉴→요청자 현재 채널→선택 요청 순서로 구현한다. 사람 많은 채널 자동 선택·전체 순회를 금지한다.
- 일반 voice channel·허용 목록·사용자/봇 접근·Connect/Speak를 검증하고 Stage 채널을 거절한다. 동명 채널은 ID 기반 메뉴를 제공한다.
- allow_remote_voice_control=false에서 요청자 참여 채널/이미 봇과 함께 있는 채널 조건을 적용하고 설정 변경만 원격 대상을 허용한다.
- /입장·/퇴장을 공통 실행기로 연결하고 generation/cancellation을 적용한다. 재생 중 이동은 0.4.0 확인/보존 계약이 연결될 때만 활성화한다.
- 권한/대상 선택 뒤 실제 연결 직전에 다시 검사한다. 강제 퇴장·명시적 퇴장 뒤 늦은 연결 완료를 폐기하고 자동 재입장을 금지한다.

## 산출물

- voice selector·입장/퇴장 Discord 핸들러와 정책 코드.
- 채널 없음·동명·Stage·접근 실패·원격 대상·늦은 완료 fixture.
- 재생 기능 연결 전 음성 상태/세션 버전 인터페이스.

## LXC 검증

- DiscordBotLXC에서 fake 연결 경쟁 단위시험과 실제 테스트 Discord 입장/퇴장을 실행한다.
- T-12에서 요청자/명시 채널이 없으면 선택 요청만 하고 어떤 음성채널에도 임의 입장하지 않는지 확인한다.
- 다른 채널/권한없는 채널/Stage/동명과 연결 진행 중 퇴장·관리자 강제 퇴장을 검사한다.

## 통과 기준

- /입장은 자동 재생하지 않고 선택한 ID의 허용 채널에만 연결한다.
- T-12 실제 Discord 시험이 통과하고 T-19의 입장 단계 선행 시험에서 자동 재입장 0건이다.
- 재생 중 이동은 아직 T-13 최종 통과로 표시하지 않고 0.4.0 의존을 명시한다.

## 중단·후속 처리

- 임의 입장·원격 정책 우회·퇴장 뒤 재입장이 있으면 voice 기능 활성화를 막고 수정한다.
- T-11·13·15·19 전체 재생 시나리오는 0.4.0 상태기계와 연결 후 최종 검증한다.

## Jev API 전용 인수 범위

2026-09-27 사용자 결정에 따라 실제 제공자는 `jev-api` 하나다. [전용 계약](../INFERENCE_PROFILES.md)을 따른다. 과거 로컬 모델 시험은 보존 기록이며 이 단계의 선행 조건이나 출시 게이트가 아니다. 권한·확인·데이터·최대3단계/3 dispatch·전체12초/단계4초·실패 후 추가 전송0 규칙은 유지한다. hosted 내부 forward와 미공개 model revision은 null/unavailable로 남긴다.
