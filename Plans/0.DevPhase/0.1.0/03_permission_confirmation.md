## 목표

- 실제 Discord 권한정보를 주입받는 정책 계층을 만들고 정보가 불확실하면 변경을 차단한다.
- 확인 버튼이 권한·대상 버전 검사를 우회하지 않도록 일회성 확인 계약을 구현한다.

## 추론 프로필 적용

[Jev API 전용 계약](../INFERENCE_PROFILES.md)을 따른다. 실제 자연어 판단은 `jev-api`만 사용하며 봇과 TLS 중계·영속 원장은 DiscordBotLXC에서 별도 계정으로 실행한다. 현재 배치는 [환경 계약](../ENVIRONMENT.md)을 따른다. `mock`은 지정 LXC의 격리 회귀 전용이다. 구조화 명령은 추론 없이 실행하고, API 장애가 기존 재생·슬래시·버튼을 막지 않게 한다.

## 로컬 코드 작업

로컬에서는 아래 코드·문서 작성과 읽기 검토만 한다. 설치·lint·타입검사·시험·build는 LXC에서 수행한다.

- 일반 멤버·DJ·관리자의 조회/제안/편집/재생/설정 권한을 명세 §4 표대로 작성한다. admin_dj_override 기본은 false다.
- 저장 목록 편집의 허용 텍스트 채널과 재생 제어의 동일 음성채널 조건을 분리한다. 원격 입장 정책은 별도 조건으로 둔다.
- 자연어 제거·전체 삭제·덮어쓰기·대기열 비우기/교체·재생 중 이동·20곡 이상 추가에 미리보기와 확인을 강제한다.
- 확인 토큰 원문 대신 해시를 저장하고 actor/guild/대상 ID/기대 버전/작업 내용·60초 만료·consumed 상태에 묶는다.
- 승인 직전에 실제 역할·대상 상태를 다시 읽고 타인 승인·만료 재사용·변경된 대상 승인을 거절한다. 제안 DJ 승인은 요청자 확인과 구분한다.

## 산출물

- 정책 evaluator와 ActionPlan 검증/확인 생성·소비 코드.
- 동작별 확인 정책 fixture 및 권한정보 조회 실패/역할 해제 fixture.
- 한국어 권한·만료·충돌·재선택 오류 계약.

## LXC 검증

- DiscordBotLXC에서 FakeDiscordGateway를 사용하는 정책 단위시험을 실행한다.
- 비DJ·관리자 비DJ·설정 관리자·동일/다른 음성채널·override 설정의 허용/거절 조합을 검증한다.
- 확인 토큰을 다른 사용자·다른 guild·다른 작업·기한 밖에서 제출하고 역할/버전 변경 뒤 재승인을 시험한다.

## 통과 기준

- T-03·05의 정책 선행 시험과 N-19·20·30의 재검증 선행 시험이 변경 0건으로 통과한다.
- 모델의 높은 점수나 입력의 DJ 주장으로 권한/확인이 생략되지 않는다.
- 아직 연결하지 않은 자연어·Discord 버튼은 실제 통합 PASS로 기록하지 않는다.

## 중단·후속 처리

- 권한정보 실패 시 허용으로 처리되거나 토큰 재사용이 가능하면 즉시 수정 후 해당 시험을 다시 수행한다.
- 실제 Discord 권한 캐시/조회·버튼 연결은 0.2.0, 자연어 제거 확인은 0.6.0에서 최종 검증한다.

## Jev API 전용 인수 범위

2026-09-27 사용자 결정에 따라 실제 제공자는 `jev-api` 하나다. [전용 계약](../INFERENCE_PROFILES.md)을 따른다. 과거 로컬 모델 시험은 보존 기록이며 이 단계의 선행 조건이나 출시 게이트가 아니다. 권한·확인·데이터·최대3단계/3 dispatch·전체12초/단계4초·실패 후 추가 전송0 규칙은 유지한다. hosted 내부 forward와 미공개 model revision은 null/unavailable로 남긴다.
