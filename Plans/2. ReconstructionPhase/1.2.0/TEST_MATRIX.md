# 1.2.0 시험 추적과 판정

전체 게이트: **IN_PROGRESS**. p1~p12l의 일부 계약/격리 회귀, 제한 Jev/GPT 실호출, 테스트 서버 봇 적용은 [실행 기록](../../../evidence/public/reconstruction-120-progress.md)에 남겼다. p12k의 37/46은 stage1 개발 진단이고 목표 미달이며 독립/전체인수 성적이 아니다. p12l의 GPT 단회 full_parse 성공도 자동 복구/독립 품질 인수가 아니다. Discord API 인증·명령 등록은 확인했지만 사용자 자연어 입력5건은 모두 해석 실패해 실제 인수 **FAIL**이다. 이 표의 종료 기준 전건, 독립221·Discord 사용자 인수·이관은 미완료다. 코드·모델·DB를 실행하는 모든 시험은 **DiscordBotLXC 전용**이다. 로컬 문서 링크/비밀 패턴 점검 결과는 제품 PASS로 기록하지 않는다.

## 목록 전달 필수 하위 사례

R120-08/09/12/28/31에서 재생목록, 카탈로그, 특정 목록의entry, 대기열item, 텍스트채널, 음성채널을 각각 검사한다. 다음 항목을 하나의 ‘후보 정확도’로 합치지 않는다.

- 확정scope의 DB/API 전체목록과 전달목록의 ID집합·개수·stable order/revision 비교. 내용은 신뢰하지 않는 데이터이며 권한 밖 항목은0.
- 이름의 어휘가 직접 등장하지 않는 표현, 표시명/별칭, 동명 다른ID, 같은곡 중복entry, 인용/부정/‘none’ 제목, 이름에 주입문이 있는 사례.
- 빈 목록, 조회 실패, 불완전 페이지, 조회 중 변경, 호출 후 삭제/권한회수, 재해석 명령변경과 다른resolver, root/pass/arg가 다른ID.
- 선택지/입력 한도 직전·정확 경계·초과, 예약 선택지 포함. 초과이면 범위질문/UI이며 top-k·조용한 잘림·모든페이지 모델 호출은0.
- 새 이름·숫자·검색어는 별도 원문추출 정답으로 평가한다. 목록이 정확히 전달된 비율과 Jev의 항목 선택 정답률, 최종 명령+전체인수 정답률을 따로 보고한다.

## 독립 평가와 비용 계획

개발자료/기존1.1.6 실패/1.1.8 예문은 개발용이다. 새 독립 세트는 명확사례 max(120,3×N), 현재 N=47이면141개와 모호/부정/비명령60개, 주입/우회20개 이상으로 총221개 이상을 잠근다. C39는 자연어 진입점으로 세고 호출할 명령으로 출력시키지 않는다. 모든 공개 옵션과 I01~I08은 별도 전수 회귀도 요구한다.

정답은 명령·대상·전체인수·필요한 질문/확인·공개 범위다. 명확141개라면134개 이상, 명령군90% 이상과 잘못된/무단 실행·확인 생략·정보누출·취소후실행·중복효과0을 요구한다. 데이터를 보고 수정하면 해당 세트는 개발용으로 전환하고 새 독립 평가를 잠근다.

221개 평가만 최악 Jev1326회·LLM442회·전체1768시도다. 이는 호출 상한 계산이고 예상 실제 비용/전체 검증 예산이 아니다. 개발·준비·경로별 성능·실제Discord·기존잔여시험의 예산을 더해야 한다. 기준 비교/shadow도 별도 예산에 합산하며 운영 요청을 몰래 이중 전송하지 않는다. 실제 잔여량·유한 GPT 지출한도·가격표가 없거나 부족하면 유료 실행을 시작하지 않는다. 기존3000 원장을 초기화하거나 필수 분모를 줄여 통과시키지 않는다.
