# 창근이 개발 명세 1.1 — 최신 명세 안내

현재 개발 기준은 [개발 명세 1.2](CHANGGEUN_DEVELOPMENT_SPEC_v1.2.md)다. 이 경로는 기존 문서 링크를 위한 안내로 유지한다.

1.2는 Jev API와 local OpenJev를 테스트 프로필로 선택하는 계약, API 1.2, 제공자별 호출/forward 계측, 검증·출시 기준을 포함한다. 이전의 local 전용 설계를 현재 기준으로 사용하지 않는다. 제품 구현과 실제 시험은 아직 수행하지 않았다.
