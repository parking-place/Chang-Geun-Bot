## 결정

기존 슬래시47개와 사용자 선택/버튼 동작을 공통 명령·인자 등록부와 서비스로 연결한다. 자유로운 한국어 의미 판단은 Jev API의 닫힌 후보 선택을 사용하고, 모델이 동작을 실행하거나 임의 권한·실행 인자를 생성하지 않는다. 역할/출처·확인·자료 버전 검사는 서버의 기존 실행 경로에서 유지한다.

구조화 슬래시/버튼·정확한 구조화 별칭·문맥에 결합한 선택/확인/취소는 Jev0회다. 새 관리자 **자유 자연어**도 의미 판단에 Jev를 사용할 수 있으며 요청당3dispatch·12/4초 상한을 공유한다. [0007](0007-watch-channel-management.md)의 슬래시 `/주시`0회 계약은 유지하고, 이를 새 자유 자연어 경로까지0회라고 확대 해석하지 않는다.

주시 꺼짐/미등록 상태에서도 **기존 정적 text allowlist의 접근 가능한 텍스트 채널**에서 서버 소유자/서버 관리 권한만 관리 전용 prefix 복구를 시작하도록 계획한다. 일반 음악/편집으로 전달하지 않는다. 모든 미주시 채널을 대상으로 의미 판단하지 않으며, 운영자 prefix off·Intent/권한 미준비를 우회하지 않는다. 이 예외가 구현/검증되기 전의 “끄기 후 prefix 무응답” 동작과 과거 인수는 그대로 보존한다. 관리 복구 채널이 없으면 기존 슬래시 복구가 필요하다.

일반 메시지 답장은 공개이므로 관리자 상세를 `ephemeral` 인자만 붙여 전송하지 않는다. 내용 없는 요청자 전용 결과 버튼을 공개하고, 클릭한 interaction의 최신 권한 검사 뒤 비공개 결과를 제공한다. 따라서1.1.8은 모든 작업의 자연어 **시작**을 지원하되 민감한 결과 확인에는 버튼이 필요할 수 있다. [Discord interaction 응답](https://docs.discord.com/developers/interactions/receiving-and-responding), [메시지 컴포넌트](https://docs.discord.com/developers/components/reference).

질문/후속 답변은 요청자·채널·원래 요청·자료 버전·최대60초의 서버 발급 단회 capability에 결합한 구조화 값 보충이다. 원래 inference 요청을12초 안에 종료하고, 답장 후에는 원래 trace/누계와 결합한 파생 실행 ID·신선한 권한/버전·짧은 로컬 실행 기한으로 새 plan을 만든다. 만료된 plan을 재사용하거나 provider 기한·3회 예산을 갱신하지 않는다. 질문 대기는 취소 가능한 원장 상태로 보존한다. 의미가 달라진 명시적 새 요청만 새 inference 요청으로 처리하고 자동 재시도는 하지 않는다.

## 기존 기준과 검증

이 계획은1.0.0 승인 음원 범위와1.0.1 이후 미디어 기능의 역사적 범위를 바꾸지 않는다. 1.1.6 독립 품질 FAIL 자료는 개발용으로 유지하고 새 독립 자료를 잠근다. 1.1.7 미디어/실제 음성/8시간/운영 미완료와 사용자 지정 백업 검증 SKIPPED를 승계한다.

새 명령 경로의 제품 시험은 DiscordBotLXC에서 수행한다. 현재 소스/휠 개발 시험은 IN_PROGRESS이며 Jev 공유 예산은 실제 개발 호출만큼 증가했다. 활성 서비스·DB·채널·VERSION·태그는 변경하지 않는다. 관리자 출처와 비공개 응답의 전수 안전 회귀를 수행하기 전 기존 동작을 활성화 변경하지 않는다.
