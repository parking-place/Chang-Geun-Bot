# 0007 — 1.0.3 주시 채널 관리 명령

- 날짜: 2026-09-28
- 상태: **채택·개발 구현 — 전체 실제 인수·정식 출시 미완료**
- 요청: 앞서 후속 작업으로 남긴 `!!창근아` 반응 채널 설정을 Discord 안에서 관리할 명령으로 계획한다.
- 대상: [1.0.3 README와5단계](../../Plans/0.DevPhase/1.0.3/README.md)

## 결정

`/주시 추가·제거·목록·켜기·끄기·점검`을 관리자용 길드 슬래시 그룹으로 계획한다. 일반 음악 자연어와 분리해 Jev 호출0회로 처리한다. 주시되지 않은 채널에서도 이 그룹만 별도 관리자 검사로 복구할 수 있게 하며, 일반 명령의 채널 허용 범위를 넓히지 않는다. DJ 역할만으로 설정을 바꾸지 못한다.

주시 목록은 서버별 DB의 영속 설정으로 관리한다. 제한 설정의 기존 목록은 최초 한 번만 이관한다. 기존 공통 text allowlist는 슬래시/멘션에 유지하고, prefix는 서버가 기록한 요청 출처에 결합한 별도 동적 정책을 적용한다. 이전1.0.2의 정적 부분집합 계약은 1.0.3에서 이 방식으로 명시적으로 대체하며 이전 버전의 검증 결과를 바꾸지 않는다.

등록 채널과 켜짐 상태, 운영자 기능 허용, Gateway 본문 접근, 채널별 권한 상태를 구분한다. 명령으로 Portal Intent·봇 역할/overwrite·DJ/음성 권한을 변경하지 않는다. 현재 `일반`, `discord-bot-test` 선택은 초기 이관 자료일 뿐 재시작 때 명령으로 저장한 상태를 덮어쓰는 기본값이 아니다.

설정 revision과 채널/활성 세대로 요청·확인·재생 승인을 검증한다. 제거·끄기는 확인 뒤 관련 미완료 요청과 시작 전 prefix 승인을 무효화한다. 곡/큐/목록은 보존하며 현재 재생은 유지한다. 새 자동 시작은 유효 승인만 사용한다. 원문 메시지 삭제처럼 이미 완료한 DB 편집을 자동 undo하지 않는다.

## 이유와 구현 영향

현재 정적 채널 검사는 입력·최신 actor·공통 실행기·미디어 재검증 여러 곳에 있다. 목록 파일/캐시만 고치면 신규 채널이 실행기에서 거절되거나 일반 음악 명령 권한까지 확장된다. 원장의 policy hash도 현재는 기록만 하므로, 동적 변경은 실행 시 검증과 DB의 원자적 취소를 요구한다.

현재 DB loader는 모르는 migration도 거절하고 `SETTINGS_UPDATE`는 다른 설정 JSON을 교체한다. 따라서 별도 주시 테이블·additive migration·이전 바이너리/이전 DB 묶음 복귀를 설계한다. 새 설정/요청 이력은 롤백 시에도 보존하고 gateway 호출 예산을 초기화하지 않는다.

## 공식 외부 계약 확인

Discord는 명령 기본 권한·길드 범위·채널 타입 선택 옵션을 제공한다. 1.0.3은 이 UI 제한과 앱의 최신 관리자 검사를 함께 적용한다. [Application Commands](https://docs.discord.com/developers/interactions/application-commands)

Manage Guild와 개별 채널 접근은 구분해서 검사한다. 봇에 서버 관리자 권한을 요구하는 방식으로 설계를 대체하지 않는다. [Permissions](https://docs.discord.com/developers/topics/permissions)

Message Content Intent는 채널별 주시 목록을 제공하지 않는다. 일반 메시지 본문 접근 준비와 앱의 채널 필터를 함께 유지하며 Portal 설정을 슬래시 명령이 바꾼다고 설명하지 않는다. [Gateway / Message Content Intent](https://docs.discord.com/developers/events/gateway#message-content-intent)

확인일: 2026-09-28. 위 공식 문서 확인과 로컬 소스 검토는 이번 계획의 근거이며 실제 계정·Portal·원격 서비스의 새 검증 증거가 아니다.

사용자 구현 요청으로 1.0.3은5단계 모두 IN_PROGRESS다. 관리 명령·영속 정책·요청/재생 승인 세대·자동 회귀를 구현했다. [실행 증거](../../evidence/public/watch-channels-20260928.md)의 부분 통과와 남은 W 실제 인수를 구분한다. 기존1.0.0~1.0.2 미완료 게이트와 정식 출시 조건은 유지한다.
