# 0006 — 1.0.1 YouTube 재생·1.0.2 채널 호출 계획

- 날짜: 2026-09-28
- 상태: 사용자 요청에 따른 **개발 진행**, 사용자 구현 요청에 따라 별도 후보·부분 시험; 정식 출시 전
- 요청: 승인 음원으로 미리 등록하지 않은 YouTube 영상도 재생하고, 선택한 채팅 채널에서 `!!창근아` 뒤의 한국어 문장을 명령으로 처리한다.

| 버전 | 목표 | 현재 판정 |

여기서 YouTube 영상 재생은 음악봇의 음성 재생을 뜻한다. 영상 화면 송출·화면 공유는 포함하지 않는다. “승인 음원 매핑 불필요”는 개별 로컬 음원 파일을 미리 등록할 필요가 없다는 기능 계약이다. 공개 링크라는 사실과 콘텐츠 이용 권한·플랫폼 허용 여부는 별도로 판단한다.

개발 명세1.3과 결정0003의 승인 음원 제한은 1.0.0 기준으로 유지한다. 이후 버전의 변경 범위는 이 결정과 해당 버전 계획을 함께 적용한다. 1.0.1 계획을 기존 `youtube_audio_enabled` 플래그만 켜라는 지시로 해석하지 않는다. loader·실행기·재생기 변경은 별도 개발 후보에 구현했고 단계별 필수 인수는 계속 진행한다.

## 외부 조건과 확인 책임

공식 YouTube 정책은 API Client의 오디오 분리·백그라운드 재생과 승인 없는 영상 다운로드/캐시 등을 제한한다. Data API 키나 공개 영상 조회 성공을 Discord 재전송 허용의 증거로 삼을 수 없다. 1.0.1 Phase 1에서 실제 전송 방식과 적용 조건·허용 근거를 기록하고 기술 시험과 운영 채택 판정을 분리한다. 목표를 승인 음원만 재생하는 기존 기능으로 축소해 완료 처리하지 않는다. [YouTube 개발자 정책](https://developers.google.com/youtube/terms/developer-policies)

`!!창근아`는 Discord의 봇 멘션이 아닌 일반 메시지 내용이다. 1.0.2에는 `MESSAGE_CONTENT` intent의 Developer Portal 설정과 코드 설정, 앱에 적용되는 승인 조건 확인이 필요하다. intent는 채널별 구독 기능이 아니므로 봇의 채널 열람 권한과 애플리케이션 허용 채널 검사를 함께 설계한다. 정확한 계정 조건은 구현 시 Portal에서 다시 확인한다. [Discord Gateway](https://docs.discord.com/developers/events/gateway#message-content-intent)

출처 확인일은 2026-09-28이다. 계획 작성 이후 사용자가 Portal Intent를 활성화했고 개발 후보에서 실제 영상의 첫 PCM과 채팅 입력을 시험했다. 상세 범위와 제한은 [실행 기록](../../evidence/public/youtube-prefix-20260928.md)을 따른다.

## 공통 계약

Jev API Only·내부 API1.2·요청당 최대3단계/3dispatch·전체12초/단계4초·DJ/채널/음성 권한·위험 작업 확인·늦은 결과 폐기를 유지한다. 모델은 후보를 선택하며 미디어 주소·실행 옵션·권한을 생성하지 않는다. Jev hosted 외부 키는 gateway에만 둔다. YouTube 메타데이터 키는 기존 봇 LXC의 제한 파일에서만 읽는다.

각 버전은 README와 5단계로 구성하고 Y/C 신규 시험을 공통 추적표에 연결한다. 독립적인 개발은 병행할 수 있지만 정식 승격은 1.0.0 → 1.0.1 → 1.0.2 순서다. 1.0.1 소스 검토 중에도 1.0.2의 채널·문법·권한 시험은 기존 승인 음원으로 진행할 수 있다. 출시 불가능한 소스 상태를 후속 버전 완료로 감추지 않는다.
