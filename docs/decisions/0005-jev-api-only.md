# 0005 — Jev API 전용 개발·출시 범위

> 현재 물리 배치는 2026-09-28 [결정0008](0008-single-lxc-jev-api.md)이 대체한다. 아래 두 서버 구성은 당시 기록이며 OpenJevLXC에 새 작업을 수행하지 않는다.

- 날짜: 2026-09-27
- 상태: 사용자 지시로 확정
- 근거: “안되겠다 그냥 Jev API Only로 하자”

## 결정

0.0.0~1.0.0의 실제 자연어 제공자는 `jev-api` 하나로 고정한다. local OpenJev 모델 채택·CPU 비교·제공자 전환과 양쪽 제공자 품질/soak 인수는 현재 범위에서 제외한다. `mock`은 지정 LXC의 격리 계약 회귀 전용이며 실제 Discord 서비스에 활성화하지 않는다.

기존 DiscordBotLXC와 OpenJevLXC는 유지한다. 후자는 이름을 바꾸지 않고 TLS/Bearer 내부 API·Jev API 어댑터·영속 호출 원장만 운영한다. 외부 키는 gateway에만 공급한다. 봇은 외부 API를 직접 호출하지 않는다.

## 유지하는 기준

승인 음원 재생과 YouTube 링크/목록 관리, 실제 DJ·채널 권한, 위험 작업 확인, DB/큐 분리, 요청당 최대3단계/3 dispatch, 전체12초/단계4초, 자동 재전송/fallback0, 만료 뒤 미실행, 암호화 백업·복원·롤백은 유지한다.

Jev API 고정 후보의 독립 held-out ≥200문장·명확한 요청 의도/대상 ≥95%, 1/2/3단계 경로별 ≥100요청, ≥8시간 실제 음성 혼합 시험을 요구한다. 로컬 모델 점수나 mock으로 대체하지 않는다. 내부 forward·미공개 model revision은 null/unavailable로 남긴다.

## 코드·기록 처리

실행 설정·API 계약·봇 클라이언트·서비스 제어·candidate 설치에서 local 제공자를 거절한다. 로컬 모델 어댑터·비교 도구·공개 프로필은 실행 소스에서 제외하고 비공개 보관한다. 이미 만들어진 LXC 모델 캐시·가상환경·원장·복원 기록은 삭제하지 않으며 자동 실행하지 않는다.

[명세 1.3](../../Plans/CHANGGEUN_DEVELOPMENT_SPEC_v1.3.md)이 현재 기준이다. 명세1.1/1.2와 이전 실행 보고는 과거 기록으로 보존한다. 이 결정은 기존 실패를 PASS로 바꾸거나 전체 버전 인수·정식 출시를 완료 처리하지 않는다.
