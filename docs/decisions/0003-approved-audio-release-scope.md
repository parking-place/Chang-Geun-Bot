# 0003 — 1.0.0 재생 소스 범위 확정

- 상태: 사용자 승인
- 결정일: 2026-09-27
- 적용: 명세 1.3에서도 유지하는 제품 1.0.0 범위; 내부 API schema 1.2는 유지

사용자가 “승인 음원 재생으로 1.0.0 범위 확정”을 선택했다. 1.0.0은 전송 권한이 확인된 음원의 Discord 재생과 YouTube 링크/목록 메타데이터 관리를 지원한다. YouTube 영상에서 오디오를 직접 추출·전송하는 기능은 1.0.0에서 제외하고 비활성으로 유지한다.

## 인수 기준과 사용자 영향

승인 음원에도 DJ 권한·확인·세션 generation·DAVE·재생 제어·재시작 복구·8시간 시험을 모두 적용한다. 공식 메타데이터 경로, 소스 출처와 권한 확인된 매핑, 임시 재생 경로의 비공개 처리, 안전한 파일 경계와 링크 저장을 검증한다. 승인 음원을 직접 YouTube 재생이라고 표시하지 않는다.

사용자가 저장한 YouTube 참조는 승인 음원 매핑이 없는 경우 재생하지 않으며 지원 상태를 안내한다. 제한을 도움말·출시 문서에 표시한다. 한국어 품질·3회 상한·성능·보안·복원 등 나머지 출시 기준은 유지한다. 실제 제공자 범위는 후속 [결정0005](0005-jev-api-only.md)에 따라 Jev API 하나로 변경했다.
