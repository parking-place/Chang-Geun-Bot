# 검증 증거 보관

현재 실제 LXC 실행 증거는 없습니다. 이후 원본은 `evidence/<version>/<phase>/<profile>/<run_id>/`에 수집하며 기본적으로 Git에서 제외합니다. 경로가 만들어졌거나 양식이 존재하는 것은 PASS가 아닙니다.
